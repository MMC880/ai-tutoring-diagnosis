# 晋学智辅2.0：六步增量交付计划

授权：用户“按照这第一步到第六步”继续开发。基线8cea5d0；在现有v2目录增量实现，不改旧app/packaging，不迁移真实资料，不读取旧密钥。

## 范围和设计

沿用Electron + React/TypeScript + FastAPI/SQLite、assistant-ui。教师事实、AI候选、复测证据分别保存；原件和更正历史不覆盖。四科分开，数学提供小范围可校验演示内容，其余学科不冒充有完整教学库。Agent是受限工具调用者，本地档案才是记录依据。当前学生/学科切换不得携带上一学生的模型历史或授权。

### 1. Agent收件和失败可理解

- 保留原件15MB/12份；分析最多3张，生成去元数据、按方向纠正且限制尺寸的模型副本，显示副本限制，不要求老师手工压图。
- 收拢附件列表，显式处理中/失败/已完成；失败保留材料，禁止静默重发/切换；取消请求提示上游可能仍处理。
- 测试：大图/MPO/损坏图/配额；已有归档与窗口回归；小窗口实际截图。

### 2. 题目与知识点

- 每份已归档作业按题号登记知识点；引用该作业原件哈希、页码、原话作为证据。
- 教师可直接提供/更正；AI提议仅待确认。候选到确认是显式动作，追加修订。
- 数学种子标签仅用于索引，不号称完整山西教材库；支持老师输入其他明确标签。
- 测试：证据归属、越权/无题号、候选不进正式统计、更正不覆盖。

### 3. 个人与班级分析

- 仅按有效的教师确认错题/知识点，跨不同作业计次；展示来源，不按题号相同推断同知识。
- 班级按真实班级与学科筛选，分母说明为已收作业/已关联范围，不计算伪准确率；缺日期单列。
- 测试：跨人/跨科隔离、不同作业复现、改判和未覆盖范围。

### 4. 反馈与复测

- 为确认知识点保存待审讲解和三级训练，教师审核后才能标为可交付；答案和学生题面分开。
- 已有数学例题/符号工具可复用；缺模型/知识内容时明确说明，可手工补充。
- 复测追加独立证据；答对一次只写“本次答对”，保留原错题。
- 测试：审核门槛、答案分离、复测不覆盖原记录及统计。

### 5. 本地可靠性

- 已暂存流程可重开继续；错题改判、日期/缺页补充采用追加记录。
- 本地数据位置和备份目录明确；选择新目录不擅自迁移旧库。
- 创建一致备份、校验清单；恢复先验证且仅到空目录，不覆盖当前数据。故障注入验证回读/回滚。
- 测试：重启待办、失败恢复、备份损坏与路径逃逸、恢复后回读。

### 6. Windows试用包

- 复用已有本机打包环境冻结Python后端，生产React资源，Electron带后端与启动清理；不要求用户安装Python/Node。
- 输出完整便携目录/ZIP（不是孤立EXE），说明书和试用反馈表。
- 实际运行包、打开Agent、拖图、归档/查档、知识点/复测、备份回读、关闭再开。
- 另一台干净电脑/真实API/老师省时若不可测，明确未验证。
