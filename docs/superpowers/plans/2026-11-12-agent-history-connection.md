# 当前学生历史与归档材料的 Agent 最小连接

**目标：** 让现有 Agent 在老师授权的当前学生、学科内，先读取结构化记录，再按需读取指定作业原图；分析保存为待确认 MD，正式学情不变。

**范围：** 用户本轮明确授权设计并实现。沿用现有工程、模型循环、SQLite、原件校验和笔记保存；不升级依赖，不扩展训练、复测和整体布局。

**设计：** 增加受限只读工具模块，复用 LearningService 的作业范围核对、当前修订与原件读取。工具参数不能覆盖学生/学科；历史读取和原图读取分别由本次会话授权。主页已选作业通过既有窗口上下文带入。每次调用记录真实来源、失败与未读取状态；保存笔记时附来源回执。PDF和损坏图片明确未识别。

**默认选择（实现判断）：** 结构化历史每页最多10份，可翻页；单次最多3张原图；没有授权不提供对应工具；原图先生成既有去元数据分析副本。无真实模型凭据时只运行外部传输替身，不能宣称真实模型理解通过。
