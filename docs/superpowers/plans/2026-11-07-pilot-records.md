# 10人试点记录与耗时对照 Implementation Plan

使用superpowers:executing-plans inline/TDD及最终独立审查。继续已授权第7步准备，不代老师实际试点。

设计：独立本地试点记录页，无需先有学生卷。老师记录样本计划/已处理人数、收件/整理/核对/补拍/辅导/发放六环节人工基线与软件流程耗时（人分钟，未知为null）。支持教师自定节省目标及是否已确认，归属/识读/审核/闭环四项自填PASS/FAIL/UNKNOWN与证据备注。默认SYNTHETIC，真实试点需主动选REAL；不给任何记录自动授予正式验收PASS。

完整且基线大于零才计算净省时及比例；部分样本不推为整班。目标是否达到只作教师自填数据的计算，非现场验证。记录版本化，冲突拒绝、历史保留、备份恢复校验。不会改变学生、题目、审批或AI任务；不引入计费、心理档案、多机构或外部传输。
