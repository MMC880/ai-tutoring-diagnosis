# 晋学智辅真实模型接入与受限Agent验证

用户已明确授权接入其指定测试服务与模型并运行测试；沿用现有第一刀，不重新选型、不升级依赖。

**目标**：assistant-ui → FastAPI → 用户指定中转站，验证文本、图片、受控工具及本地待确认结果回读。默认 `deepseek-v4.1-flash-1017`，不自动切换备选模型。

**实现选择**：复用已安装 httpx、Pillow、assistant-ui LocalRuntime；OpenAI兼容 Chat Completions 协议由Python转换。当前无需引入LangGraph、生产CopilotKit或新的Agent平台。

**范围**：
- 配置和密钥只保留在后端进程内存；设置接口不回传密钥，不写源码、浏览器存储或报告。测试退出即清除。
- 无Key时保留明确标注的本地模拟。真实模式失败返回失败，不回退为模拟或其他模型。
- 当前发送的文字、所选图片、主动导入摘要才发送；摘要中的当前学生称呼替换为“学生A”。不自动打开原件或其他学科。
- 内置中文Skill作为提示流程；模型调用限定为读取所选摘要、保存AI待确认笔记。真实写盘后返回回执与SHA-256；不写正式学情、不执行任意代码或路径。
- 图片按真实编码解码并重建PNG，去掉附带元信息；MPO只取主帧。PDF可本地保存，但本轮不假装解析或送达模型。
