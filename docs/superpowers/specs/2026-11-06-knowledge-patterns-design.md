# 反复问题的知识依据与原题证据

继续已授权7步计划第4步，沿用本地Python/SQLite/原生JS。以老师确认过的题目为学习证据，不新增自动诊断、评分阈值、心理标签或外部模型调用。

原汇总按知识名称和题型文本组成分组。改为：已关联教学条目按material_id+entry_id稳定归组，版本仅固定每题依据；同条目跨版本改名、不同题型可一起看，不改旧快照。不同资料／条目即使同名也不自动合并。没有引用的旧记录继续按原文字标签归组，明确是待核对的标签线索，不和已关联组混并。

选择该方式是为复用v0.11审核及固定版本引用。纯文字合并无法避免同名异义；AI猜同义将增加未授权语义判断，均不作为当前实现。需统一关联时，老师回原卷选择同一个已审核条目，保存并重新确认后更新汇总；原历史保留。

每组展示归组依据、曾用知识名称、不同题型、各结果数量、原卷／题号／版本、确认时间和具体原答／错因记录。单次、同卷多题、跨作业仍只是观察信号；缺页与待核对不计为不会。作业份数不等于独立作答次数，确认时间不冒称作业日期，日期和独立条件仍由真实试点核实。

沿用按同原件集合+题号的保守去重及最近确认，复测单列，当前待审改关联不提前搬移证据或授权补练。资料历史版本及老师核对依旧可从事件只读窗口追溯。

不增加业务库写入接口或自动填充四科底稿；本次分析只读。保留v0.11包及改前副本。第4步真实验收仍要老师提供同一学生跨次作答并核实分类、时间与独立性，不以合成检查替代。
