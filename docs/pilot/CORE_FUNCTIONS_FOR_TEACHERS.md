# 晋学智辅｜核心功能说明书

教师试用说明初稿 · 2026年11月8日

本说明以当前已实现的本地应用为准，供甲方演示和试用范围核对。Windows EXE尚未封装，不能将本稿理解为安装包已交付。

## 解决什么问题

为每个学生建立可以持续积累、回看依据的数学学习档案。老师登记已经批改的作业结果，将问题题号与知识点关联，查看历次表现，再安排复习和复查。

当前首先服务山西初中数学教师。系统辅助整理与反馈，老师负责批改口径、教学安排和最终确认。不建立心理档案，不推断学生心理或人格。

## 三个日常入口

|入口|老师可以做什么|需要知道的边界|
|---|---|---|
|学生档案|按姓名或编号找学生，回看其作业、已确认的问题、知识点线索和已有复测记录|单次错题只表示本次存在问题；同名学生靠编号区分|
|登记作业|选学生、选作业，保存原件，登记题号、判定、知识点与反馈，核对后确认归档|保存待审不等于确认；未录入的题不能当作做对|
|班级学情|查看当前作业批次中已确认的问题、涉及学生及原题证据|目前按单个作业批次统计，尚未实现跨多次作业的班级累计分析|

AI服务、教学资料、备份等较少使用的操作，统一放在“设置”。

## 老师怎么完成一次登记

1. **先找学生。** 核对学生编号和称呼，再打开该生的一份明确作业；新作业先创建待录入草稿。
2. **收好原件。** 可一次选择多张照片或多个文件；支持PNG、JPG、JPEG、PDF、DOCX，每个文件不超过15MB。老师的原题或参考答案可另外附上，没有也可以先登记。
3. **核对问题。** 记录题号、本次对错和知识点，必要时展开原题、原答、老师批注与判断依据。识图只是辅助；看不清或判断不一致时保留待确认。
4. **保存待审。** 中途可先保存草稿，之后继续核对。此时不会把草稿结果作为正式确认记录。
5. **确认归档。** 老师核对当前已登记题目，明确勾选并确认后写入学生档案；现有流程按这份作业的全部已登记题目一起确认。
6. **回看与跟进。** 从档案查看证据，结合已有练习、补习与复测记录观察后续变化。只记录真实发生的学习反馈。

## 学习档案怎样积累

档案保留原来的错题与确认历史，并呈现后续修订和复测表现。改判追加新记录，不抹去原来的判断。重复确认同一版本不应重复增加记录。

知识点归组帮助老师发现值得关注的重复问题，但标签相似不一定代表同一知识点。老师需要核对关联依据；缺少可靠关联时，系统只能提供线索。

- **做错一次：** 记录本次问题，不直接认定为长期薄弱。
- **后续又错：** 结合不同作业、原题和作答记录，判断是否存在反复问题。
- **复查答对：** 增加一次正向证据，不自动等同于已经掌握。
- **缺页、字迹不清或尚未登记：** 单独保留状态，不计成“不会”。

## 所有作业留档，与统计范围有什么区别

已收进系统的作业应保留记录。统计范围只是决定“这一次看哪些记录”，不决定“哪些作业要不要保留”。例如查看一次月考，不应删除其他月考。

**当前班级页面只统计所选作业的批次。** 学生个人档案可以回看已有历次记录；跨作业累计的班级共性问题仍待实现。甲方演示时应明确这一点。

## 照片、AI与练习

当前支持选择多个文件导入；手机拍好的照片可先传到电脑再选择。**拖入文件导入、软件直接调用摄像头拍照尚未实现。** 导入原件不等于自动识别完成，也不等于已经归档。

已有照片辅助和AI候选分析入口，但需要核对服务是否支持图片，并经老师复核。未验证真实手写批改准确率，不能承诺拍照后自动判完。

已有讲解、练习审核和复测追溯能力。三级练习定位为“基础巩固、综合运用、迁移挑战”，AI生成内容须由老师审核；当前不能承诺任意数学知识点均有可靠模板和可直接发布的题目。

## 本地资料与使用边界

学生身份与完整学习档案以本地保存为原则。使用外部AI时，按具体操作预览拟发送材料并确认；“本地软件”不等于AI完全离线。不要把密钥或整份学生资料库当作试用反馈发出。

当前还未交付Windows EXE，也没有家长端、会员收费或云同步。建议本次甲方演示先使用合成资料，重点确认操作是否容易理解、档案是否有用。

## 试用应该得出什么结论

先判断老师能否独立找对学生、登记一份作业、区分待审与归档、回到档案找到依据。再记录哪些环节费时、出错或难懂。实际试用前，不宣称已验证教师省时或学生提分。
