# 晋学智辅：首轮教师试用包，从这里开始

封装日期：2026-11-08。功能内核：v0.26。用途：让老师体验现有本地作业记录、个人档案、知识问题和补练复测流程，收集操作反馈。

这是需要已有Python环境的本地试用包，尚未内置Python，尚不是免安装EXE。无需为了体验合成流程填写AI密钥，也不会自动发送照片。

## 打开

1. 将ZIP完整解压到一个新的独立目录，不覆盖已有晋学智辅目录或学生资料。
2. 打开Jinxue-Local文件夹，双击“启动.cmd”。需要Windows、Python 3.12+和依赖python-docx、pypdf、Pillow；启动器会检查，不会自动安装。
3. 浏览器通常打开http://127.0.0.1:8765。若提示端口冲突，请按提示处理，不结束未知进程、不删除数据。

如果未满足环境条件，先看README和“启动与检查说明.md”；不要将启动失败当作资料丢失。关闭浏览器不等于关闭后台服务。

## 第一次体验：只用包内虚构样例

1. 点击“试一份四题合成样例”。该样例的题目、原答、结果都是预设演示，不是照片识别效果。
2. 在整卷页查看学生、作业、各题原答、结果、知识点和疑点，体验手动编辑、查题与保存。确认时核对所显示的版本。
3. 在个人档案查看确认历史、知识问题和原题证据；班级页目前只汇总同一作业批次，不是长期班级统计。
4. 从已确认的问题题目进入补练。可手动建立练习，或在另行配置AI并预览授权后拟候选；不要把二次函数演示模板套到其他知识。
5. 演示时可用明确标记的虚构作答体验复测登记；真实使用时只能填写学生实际作答，注明独立、有提示或条件待核。
6. 需要报告时预览并选择Word或打印页；结束前到“本地资料管理”创建备份。

不要将虚构样例的正确率、复测或耗时当作真实学生记录。测试与真实使用建议分目录保存；本包不带任何真实学生资料或API密钥。

## 现有材料怎样使用

现有版本可逐生上传材料、手工编辑或导入单卷questions JSON草稿，核对后归档。它尚不支持老师直接上传多学生Excel批量结果；原卷也尚未建立供多生共用的题目模板。

照片是辅助入口。当前第4页真实样本曾因JPG内部为MPO双帧而拒收；普通JPEG可用不代表任意照片都兼容，MPO和侧转处理还需改进。不必为体验档案流程先解决全自动识图。

## 这次请老师重点体验

- 登记结果、关联知识及确认是否费时，哪些字段重复填写。
- 能否快速找到某学生之前的具体问题及后续表现。
- 本批共性是否能追到学生和原题。
- 补练、复测及备份是否容易理解。

包内“第一版范围与待补项.md”列明新方向尚未接通的部分，不将本包称为新MVP已全部实现。
