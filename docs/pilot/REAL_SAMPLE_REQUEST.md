# 给老师的首批真实卷面取样清单

2026-11-06。用于真实材料试点准备，尚未接收、读取、识别或外发学生材料。当前v0.8先验收数学；英语、化学、物理可一并留样，分别记录为后续学科待验证，不能据数学结果标记通过。

## 建议首批材料

| 材料 | 建议数量 | 用途 |
| --- | --- | --- |
| 一名学生的完整数学试卷或作业 | 1份，含全部页、题干、图形和实际解题过程 | 跑整卷收件、识别、核对和待审流程 |
| 书写清楚、普通、较潦草的学生卷面 | 各1页；尽量使用同一套题，完整卷中的页面可计入 | 在题目与拍摄条件接近时比较手写识别情况 |
| 同一名学生的英语、化学、物理已完成卷面 | 各1份，可稍后补 | 为后续学科适配留样；本轮不沿数学提示词作正式批改 |
| 对应原卷、参考答案和教师判断 | 每套1份；照片、PDF或DOCX均可 | 核对原题、答案及判分依据，教师结论与识别输入分开 |

优先包含有实际过程的数学题，如分式/方程、函数、几何证明或带图解答；有自然涂改、划掉重写、分数、根号、上下标的页面可保留。若有真实跨页同题，再补前后相连两页，不用为凑样本故意制造错误或潦草。

尽量提供未批改照片，把老师的对错、步骤判断与必要备注另给。只有已批改版本也可留样，注明有教师批注，测试时单列，防止把读红笔答案当成理解学生过程。

## 拍摄和命名

- 每页一张原始JPG/PNG，尽量正对、光线均匀，拍全题号、题干、图形和步骤；避开手指遮挡、反光和裁掉页边。
- 优先原图文件，避免截图或反复转发压缩。保持原件，另做去标识测试副本。
- 比较书写时尽量保持相近拍摄条件；若测光照/角度，另用同一张卷面拍清晰与日常条件两张，单列比较。
- 使用测试编号，如ST001、ST002；文件示例ST001_数学_P01.jpg。同一学生跨科编号一致；身份对应表仅本地保管。
- 学生姓名、考号、二维码/条码、学校班级及联系方式等在测试副本中去除；保留数学题目和作答。学校/班级测试标识可另用代号管理。

## 授权和测试边界

老师先确认材料可用于本次测试，以及范围属于“仅本机留样”还是“允许去标识后的必要题目/笔迹送入指定模型”。身份对应关系、原件和完整学习档案留本地；收件本身不视为模型外发授权，发送前仍逐次预览确认。只收学业作答，不收心理等无关档案。

## 拿到材料后的验证顺序

1. 本地登记科目、试卷版本、学生代号、页码、是否已批改及可用范围；核对是否缺页、归属是否一致。
2. 先数学单页，分别核对题干/符号/图形信息、学生原步骤和识别疑点；对照老师独立结论再测判题。
3. 再跑数学整卷，核对漏题、跨页内容及原记录保存；实际测量采集、框选、识别纠正、复核等总耗时，并与老师人工处理同类材料的耗时比较。
4. 记录原件中实际出现的内容与AI多写/少写/误读项、教师改判和不确定处；缺页/看不清单列，不认定学生不会。
5. 学科和书写类型分别报告。首批用于发现问题，不据几页样本发布整体准确率或商业可用性结论；后续扩大样本再定验收门槛。

## 可直接转发给老师

老师您好，我们准备测试一套辅助整理学生作业的系统，先从初中数学开始。想请您提供一名学生做完的完整数学试卷，以及书写清楚、普通和较潦草的学生卷面各一页，尽量是同一套题，完整卷中的页面也可以使用。请同时给对应原题、参考答案及您判断的对错；最好学生照片未批改，教师判断另给。手机每页拍一张清楚原图，保留题干、图形和解题步骤，先去掉姓名、考号、二维码等身份信息，用学生代号区分。英语、化学、物理各一份也可以一并准备，先分别留样，后续逐科适配。请同时说明材料允许仅在本机测试，还是也允许去标识后的必要题目和笔迹发送到指定AI模型。测试反馈由老师复核，不自动发布学生结果。
