# 第一版范围与待补项

日期：2026-11-08。包名：首轮教师试用包，内核v0.26。本包封装现有实现，不通过改版本号声称已完成新的学习档案MVP。

## 当前可以体验

|能力|现有范围|
|---|---|
|学生与作业记录|逐生建卷、可选实际日期、附件整理、手工录入、单卷JSON草稿导入、逐生确认|
|个人档案|历史／当前确认／待审修订分开，原题追溯、知识组与成功表现保留|
|知识问题|已审核资料条目或文字标签归组，同卷多错与跨份线索、重复材料控制|
|共性统计|当前作业批次内按学生去重、展示知识问题和原题证据|
|辅导与复测|已确认原错题的三档候选、手工练习、教师审批、版本化复测及跟进|
|资料与报告|本地保存、备份恢复、Word报告和打印页、AI必要材料预览与逐次授权|

## 按最新方向，后续集中补齐4项

1. **原题复用与便捷输入**：同卷原题尽量录一次；各生关联问题题号；增加老师能用的表格批量入口及记录覆盖范围。
2. **独立知识关联与档案主入口**：知识身份不依赖先导入教案；学生的问题、历史与后续表现成为主要操作入口。
3. **班级跨次统计与复习建议**：班级不等于作业批次；明确成员、观察范围和覆盖情况，给出可追溯的复习建议。
4. **档案驱动三档复查**：从历史知识问题挑选复查目标，复用现有候选、教师审核和复测机制；同时允许老师自备任务及一般补习回档。

这4项是收尾迭代方向，不在本包中冒称已完成。三级复查继续保留在目标闭环中；识图辅助定位保留，不要求逐字转写完整过程；原题条件仍须可靠。

## 使用边界

- 现有启动器需要已有Python和依赖；新电脑环境兼容与免安装EXE尚未验收。
- 软件测试和合成演示不代表真实识别准确率、出题质量、教师省时或学生提分。
- 原始照片、身份关系与完整档案保留本地；外部模型仅在本机配置并逐次预览授权后使用。本包无密钥，不自动调用接口。
- 已有真实试卷分析只保留在研发电脑，不随试用包分发。
- 没有心理档案、会员支付、家长端或多机构平台。

第一次体验目标是老师能评估现有操作流程与缺口；正式对外收费销售仍需后续业务、运行环境和数据边界验证。
