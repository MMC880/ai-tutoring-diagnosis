# 数学第一版：7步交付与验收计划

日期：2026-11-06。状态：提交用户审阅的阶段计划。本轮只整理计划，不改应用、不导入真实档案、不调用外部模型。具体界面与实施任务在对应阶段细化，不把本文件当作全部细节已定的工程设计。

## 已确认的主线

每个学生有独立本地学习档案。老师负责主要判卷，系统整理经过确认的错题与知识点，累计反复出错的证据，定位需要补的内容；基于该内容由AI拟讲解与基础、综合、迁移三个档次的新题，经老师审核后用于考察；复测结果继续累积，保留原错题和最新表现。心理档案不进入本项目。

数学先行，覆盖目标为完整初中数学。其他三科照片目前作为未来扩展的样本，不因已收到就列为本次7步的四科正式交付。

## 三级难度的当前含义

1. 基础巩固：紧扣原薄弱考点或步骤，先核对最核心的理解/操作。
2. 综合运用：该考点与其他初中知识组合，增加必要的联系与步骤。
3. 迁移挑战：更换情境、表示方式或问题结构，要求识别并迁移方法，仍限初中数学。

这是难度方向，不是机械按题干长度分档。具体题量、提示、训练顺序随阶段细化，先拟候选由老师选，不自动一次发三套或凭一次答对升级。

## 两个明确交付点

- 第6步通过：单个学生的真实“查漏—补习—新题复测—更新”闭环可用；不称10人或全部初中知识都已验收。
- 第7步通过：数学第一版本地试用达到本阶段目标。完整初中数学是内容目标，验收要列出实际验证的知识领域与未验证项，不把少量样本外推为全领域准确率。

付费会员、充值与用量结算、多机构商业权限、其他三科正式上线属于后续阶段，不计入这7步。现阶段不承诺商业版已完成，也不给缺少材料和实测依据的固定完工日。

## 缺材料时怎样继续

- 老师暂未提供教案：可继续收件、教师确认、个人档案和待确认目录，不用空等；资料导入验收暂留待完成。
- 暂无同一学生第二次作业：可以验证处理逻辑、注明为合成测试；真实跨次反复错误不标通过。
- 暂无学生复测：讲解与题目草稿可以准备；不能虚构复测或自动代老师批准。
