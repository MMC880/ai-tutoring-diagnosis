# 照片作业到精准补练是当时开发主线

本决策已由[ADR-0003](0003-learning-archive-first.md)替代；以下保留当时背景，不作为当前优先级。

用户当时明确：核心在照片识别，识别后找到孩子的题型问题；同类型题反复错需要积累，记录待补知识点，再完善讲解与三级练习。

确认的优先级：照片识别→问题定位→重复错误证据及本地档案→针对性讲解和三级补练→复测更新。完整初中数学仍为目标，老师仍逐生整卷复审。文件兼容、导出、界面收尾作为支持工作；收费和其他学科后排。

取舍：先围绕学生照片及后续辅导验证业务价值，通用Word／PDF兼容暂不作为首要迭代。已有文件能力保留，原题答案仍可辅助照片核对。

继承的边界：未核清识别不判对错，错因不确定保留待核实，原错题历史不删，单次正确不等于掌握，心理档案始终排除。

尚未决策：重复多少次认定薄弱、不同题型如何归并、补练数量与难度选择、复测间隔、真实照片质量和省时门槛。反复错是薄弱点信号；“重复错误一定代表知识缺失”不作为确定诊断规则。
