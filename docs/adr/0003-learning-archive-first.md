# 学生长期学习档案是产品主线

用户明确调整方向：老师负责试卷、作业、教案和教学，系统核心是每生长期可追溯的数学学习档案，关联历次作业、错题、老师反馈、补习与复测，识别重复知识问题和班级共性，为老师提供复习建议并跟踪效果。手动和批量输入教师批改结果是正式入口，不依赖OCR全自动成功。三级变式与学习方法库属于后续能力，不作为当前开发阻塞项。

取舍：将投入从OCR、自动批改和单题解析优先，转为记录可信度、知识关联、班级统计和后续反馈；保留已有照片分析、原始证据、候选讲解及应用模块，不重建项目或删除成果。照片处理与出题继续可选使用，但不决定档案MVP能否交付。

本决策仅记录用户已明确的职责和优先级。具体MVP字段、班级／作答次关系、批量表格格式、知识目录、统计和建议规则仍见[讨论稿](../design/LEARNING_ARCHIVE_MVP_REFOCUS.md)，没有批准执行数据迁移或新功能开发。心理档案禁区、本地身份边界、教师确认与保留历史继续适用。
