# v0.19 同批连续审核交付

2026-11-07。起点4998fb7，功能分支feature/batch-review-v019。本次完成老师逐生整卷审核之间的手动衔接，没有新增自动批准、自动保存或学生发布。

## 老师可见的变化

整卷页顶部显示本批已收、本版已确认、待审及有处理提示的卷数，并显示下一份同批待审学生。按原有学生编号顺序循环，跳过当前及已确认卷；确认当前卷后仍留在当前学生。当前待审而其他均确认时保持待审提示，未知应收人数仍为未知，缺材料不因确认而解除。

未保存内容仍需老师决定是否放弃。点击下一份时固定页面显示的候选，再重读当前卷、目标卷和最新清单核对身份及版本；外窗改判或确认后停止切换，不擅自改跳别的学生。请求期间编辑、添加题目、打开窗口（包括已关闭的窗口）都会使切换失效，保留内容并提示重选；读取失败时禁用旧候选，可刷新恢复。

## 实现与审查

新增web/review-flow.js及连续审核使用说明.md，复用既有收件、整卷和bootstrap读取接口；后端只改静态文件白名单与版本号，没有数据结构迁移或业务写入接口。

独立审查发现并复现两个Important问题：新增题目未计入输入事件而可能丢失；候选被外窗确认后可能静默改选另一人。分别通过统一changed()变更代次与固定显示候选修复。Minor的取消无提示/按钮停用同时修复，并增加弹窗打开再关闭的失败复现与回归。旧全局busy所有权问题未在本轮重构，不宣称全局并发问题均已修复。
