# v0.23 个人学情报告

目标：老师从一个学生的本地档案预览教师核对稿，再选择可编辑Word或打印页/另存PDF，减少手工整理。沿用已有Word/打印输出，不新增存储表或发布功能，不自动向家长/学生发送。

报告范围为当前去重的已确认原卷记录、知识问题线索和完整补习复测摘要（含未复测的各版本题面与审批状态）。注明未确认草稿不计作学情，待核对/缺材料不算不会；记录时间不是实际作业日期，次数不是独立作答次数，一次答对不认定掌握。当前知识组与建立补练时的固定来源分别保留。每组练习当前版本的观察按本版本复测计算，旧版迟交与历史另列，不以旧结果代替新题面。

新增只读profile_report.py：从Store.profile的单次返回构建报告块，并对原始profile和该学生全部试卷版本守卫的规范JSON生成SHA-256指纹。指纹包括确认/草稿版本标记、教学关联和练习/复测历史；本学生任一档案内容变化必须重新预览，其他学生变化不影响。缺学生拒绝，空确认报告明确无记录，不填造结论。输出是教师核对稿，无学生发布或正式验收批准。

接口：GET /api/profiles/<id>/report返回student_id/title/fingerprint/blocks；GET /api/export/profile/<id>.docx?fingerprint=…及/print/profile/<id>?fingerprint=…重建并比较指纹再输出，缺/错误指纹拒绝。只允许教师稿，不提供学生版参数。报告只在内存生成，下载/另存由老师决定，不写成绩、审批、报告库或外发模型。

前端档案摘要区加预览按钮，使用独立report-panel.js。预览转义全部文本，默认未选格式且未勾核对；老师选择Word或打印页并勾选本次核对后才可继续。界面核对勾选只是本次导出操作，不是服务端权限边界或学生发布审批。再次读取指纹，下载端仍独立比较；切学生/切页/开新窗口使迟到预览或下载失效。打印在点击时同步创建空白窗口并断开opener，慢核对后再导航；弹窗受阻保留预览并提示，失败或窗口变更关闭空白页。打印新窗口服务端再次核对指纹，变更时拒绝旧稿。

测试先RED/GREEN，验证学生隔离、去重/改判、缺失与草稿、固定旧版来源、当前版与历史复测、只读及指纹冲突；HTTP输出DOCX结构与打印转义；浏览器预览/选项/勾选/下载/迟到/变更拦截、窄屏，并渲染合成打印页生成PDF核对。复用已有OMML简单公式能力，不声称复杂公式/真实Word客户端或纸张打印通过。

完成完整Python、受影响档案/知识跟进/待办回归及独立审查后，完整备份并更新本机0.23，只读核验数据不变，白名单交付包和本地提交。真实教学质量、老师省时与未成年人数据用途授权仍依既定边界核实。
