## 已实现

| 环节 | 实际行为 |
| --- | --- |
| 本地收件 | 学生编号与批次归属；保存 PNG/JPEG/PDF/DOCX 和老师参考答案；提取 PDF/Word 文字供核对 |
| 整卷审核 | 原件对照、人工录入／结构化 JSON 草稿导入、逐题状态与知识点／错因备注、保存草稿、整卷确认 |
| 本地档案 | SQLite持久化；确认事件只追加；修订保留旧历史；刷新与重开存储仍有数据；原卷与复测分开 |
| 班级共性 | 同批次、同题号且题干一致；最新已确认状态；正确/错误/部分/待核对/缺材料分列；展示二元分母 |
| 补练复测 | 教师编题；顶点式三档自编模板；审批绑定版本；学生导出不含教师答案字段；复测记独立条件，一次答对不判掌握 |
| 备份恢复 | SQLite一致性快照＋附件＋SHA清单；恢复前验证与安全备份；损坏备份不替换现库；需明确确认 |
| Word/PDF | 实际 DOCX，A4/2cm、原生 OMML文本和简单上标；PDF 由本地打印页在浏览器另存；按需单选格式 |

## 独立审查与修正

独立只读审查发现：同卷题干校验原先使用其他卷所有历史题干，可能接受过期题干并混算。新增失败回归后修为“只比较每题最新已确认版本且题干集合必须一致”；33项回归通过，审查者独立复核相关5项通过。

另补上未审核原卷修订不能建立新补练的后端限制。Windows测试路径改用项目内隔离临时目录，测试夹具显式关闭SQLite连接；未通过删除用户文件或调整全局环境绕开错误。

## 未完成与边界

- 无自动 OCR、AI批改、模型接入或完整题库／知识点目录；当前是人工／WorkBuddy结构化草稿加本地管理。三档模板只有顶点式演示。
- 真实手写准确率、真实资料处理与最小必要外发、十人老师净省时、实际纸张打印、复杂公式与几何图尚未验收。
- 单机HTTP服务仅用于本机单人试用，不能用于公网、多人机构部署；身份权限、商业化、API中转、会员计费未实现。
- 补练修订会撤回当前审批；当前仅保留练习最新编辑行，已录入复测保留当时练习快照。不支持旧练习版迟交录入和单独追溯未复测的旧练习版本，此限制须后续完善后再扩大试点。
- 原型和既有WorkBuddy包、62条历史未作为本地App数据迁移或改写；不是宣称旧环境本轮重新验收。
