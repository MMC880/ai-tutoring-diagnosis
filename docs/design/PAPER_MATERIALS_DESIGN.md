# 同一学生原卷补交与附件整理

2026-11-07，依据用户继续开发与老师批量作业减负方向。现有收件可多选附件，但建卷后没有补交入口；缺页只能停留在原状态。本轮补齐同一原卷的材料更新，不扩展为自动跨学生分配。

采用独立材料编辑弹窗及版本化附件更新API，复用现有本机文件上传；相比重建整卷，能保留原学生与历史；相比自动拆卷，不需要猜测学生归属。

老师打开当前学生整卷，在“补交与整理附件”中查看原材料、选择新增文件、注明作业/参考用途并上下移动顺序。已有原件不能在本入口删除或更改用途；只允许撤下尚未保存的新文件。文件名和数量不能证明页码或完整，老师对照原件排序。

保存前明确显示学生编号/称呼、批次和来源版本，勾选“确认材料属于本卷并保存待审”。新增/排序使原卷版本加1，confirmed_version保持旧值；旧确认事件保留，题目作答、判定和MISSING不自动改变。完全相同的已存顺序/用途保存不增版本。原有最多20个附件和15MB/文件限制继续适用。

接口POST /api/papers/<id>/documents，输入version、student_id、documents（完整有序id/role列表）、consent=true。版本严格整数，学生必须匹配，已有材料完整保留且用途不变，拒绝重复附件ID、旧版本、删除或替换原件。新文件可与旧文件内容相同，仅按既有批次页提示重复，不静默丢弃。附件更新与版本写入在同一事务内，无学习事件写入或外部AI调用。

上传完成但尚未挂卷的文件保存在本机。中途失败保留当前弹窗已上传ID以便本次重试；不自动重复上传或自动重试请求。保存前取消不删除原件或修改卷面；已经点击保存后关闭，不能撤销可能已提交的更新，可能留下已暂存文件；无跨会话恢复承诺。关闭、切页、切学生或编辑变更后，迟到结果不能附给别的学生或覆盖当前页面。

验证使用隔离合成照片和虚构学生，覆盖补页、排序、重复提交、旧版本/学生错配、保留旧确认与缺材料、上限、HTTP保护、失败重试和页面来源失效。真实卷面本轮不导入或确认。备份继续保存原文件和各版确认快照；旧来源AI任务因卷版本变化按现有规则失效。

历史保护补充：增加paper_document_versions仅存附件元数据快照，首次变更保存0号原始锚点及变更前后版本，不修改旧确认事件。历史原件回看与学习证据去重按事件版本选快照；旧备份可加表迁移，恢复拒绝缺锚点、跨卷附件、丢失变更前版本或与当前材料不一致的历史。

审查修复：meta中单独登记已发生材料历史的卷，恢复必须与快照卷集合一致，避免把历史整段删除当旧格式。异步挂卷成功总会标记页面缓存失效；返回或切页按代次重新读取，读取失败明确“已保存，不要重复保存”，同步前阻止旧缓存继续操作。
