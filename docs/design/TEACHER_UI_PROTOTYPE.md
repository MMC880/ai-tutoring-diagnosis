# 三入口教师界面原型

2026-11-08。基点 `39f4008`，独立分支 `prototype/teacher-three-entry`。用户已授权先做原型供选择，选定后才形成规格与任务；当前只交第一步。

## 设计与范围

回答的问题：逐生跟进、当天作业、班级备课，哪种组织方式最容易用？原型沿用原 `app/web/index.html` 入口与 #profile、#intake、#class 页面概念，通过 ?variant=A/B/C 切换。原开发目录保持不变，不重写已有业务。

继续 Python、HTML/CSS/原生JavaScript，无前端框架/新依赖。继承青绿品牌色，文字 #20383c、次要文字 #667c81、操作 #14665f、背景 #f2f5f6、线条 #dce5e5、问题提示 #8b5c13。中文使用本机微软雅黑UI，正文14px、标题27px，左对齐。用记录行和表格呈现老师实际工作，不堆大数字卡片，不下载字体图片。

```text
A 推荐：品牌与三个入口
        学生列表 | 当前学生 → 知识问题 → 历次记录
B      品牌 / 班级
        三个入口 / 学生选择
        当前作业与学生跟进 | 当天任务
C      三入口侧栏 | 班级与学生选择
                  知识列表 | 证据过程 → 复查
```

三种方案结构不同，不只是换颜色。A适合逐生跟进，B适合集中过作业，C适合从知识问题展开。设置仅演示AI服务、备份、教学资料的位置，不占主菜单。

## 可操作原型

- 三方案、三个入口、左右方向键；输入/下拉框和弹窗中不截获方向键。URL保留方案与页面。
- 10名虚构学生，可切换/搜索、查看不同记录及空档案。
- 问题关联原题和历史；单次错误不判长期薄弱，一次正确只记改善证据。待核对、缺材料不记错。
- 按题号选教师结果、暂存、核对并模拟确认；每人示例草稿分开，刷新重置。模拟确认不回填预设历史/班级统计，正式版一致性写入另按批准规格实现。
- 班级可切本次作业/三日记录，问题人数按学生去重，覆盖范围明确；不将未录当正确，不计算全班正确率。
- 分式知识提供预编基础/综合/迁移三档及教师答案，可模拟安排一题，不调用AI，不发布，不编复查成绩。
- 照片入口只演示题号定位，不选文件、不识图、不外发。无真实资料、心理功能、密钥输入或实际备份恢复。

## 打开

在原型工作区运行 `python app/preview_teacher_ui.py`，打开输出URL。仅监听本机，默认8766，占用时改空闲端口，不终止其他服务。静态预览器只提供三个固定资源，不启动正式应用/Store。也可双击 `app/web/index.html`，页面不依赖API、浏览器存储或外部资源。

底部A/B/C与左右箭头用于比较，“原型状态”显示当前布局、学生、页面及模拟记录数。建议试：学生01看依据→登记作业→切学生→回档案→班级点某学生。模拟只用于界面选择，不代表正式业务实现。
