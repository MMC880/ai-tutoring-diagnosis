# 本地照片工作流 v0.3 交付记录

日期：2026-11-05。沿用已确认的老师逐生整卷工作流，未增加心理资料、会员收费或多机构端。旧prototype、WorkBuddy样例与62条历史事件、v0.1/v0.2源码包保留。

## 本轮实现

- 当前学生作业图片归属校验，服务端裁切、白色遮挡、EXIF方向处理及去元数据重编码；浏览器只提交坐标，实际PNG可预览。
- 当前密钥／模型会话的随机数字图片验证，未通过不发送作业图片；所有外发逐次授权，无自动重试。
- 图片模型只转写。原件、原AI结果、人工修正、疑点、来源题号与版本独立留存；未核清的识别状态不能记对错或进入文字诊断。
- 失败图片可无密钥在本机人工整理，只存新待审卷，原错误、未知状态及用量保留。
- 教师Word核对报告加入独立识别疑点，避免混入学生错因。

修复了疑点文字清空绕过状态、图片切换旧回调覆盖当前附件、关闭弹窗的隐藏题目混入整卷保存等问题；保留先失败后修正证据。新增响应诊断只保存有界、脱敏最终结果和验证原因，不保存思维链或密钥；旧失败不能补造原因。
