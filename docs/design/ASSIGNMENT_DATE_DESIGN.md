# v0.25 作业／考试日期及历史依据

目的：明确原题来自哪次实际作业，区分老师提供的作业日期和系统写入时间，为跨次问题核对提供依据。日期是老师选填的日历日期，不从照片、考试标题、文件名、上传时间或电脑当前日期推断；未提供保持空，界面明确“未提供”。不据日期新增掌握、独立性或错误次数判定。

采用独立paper_assignment_dates变更表，键为paper_id和生效version，值为YYYY-MM-DD或空。读取某卷某版本取不大于该版本的最近变更，无变更则空；不回填旧历史。create_paper接受可选assignment_date；已有原卷使用专门update接口，按期望version更新，变化时原卷version加1并写入日期变更，同事务提交；数据库更新同时比较期望版本并检查受影响行，拒绝跨Store实例的过期写入。相同日期幂等，不追加版本；无效日期/旧版本不写。日期修订使原卷待审，确认仍由老师独立操作；原题、原答、原批改和旧事件不改写。补页、普通草稿修订沿用日期，不需触碰各处版本更新逻辑。

读取当前卷返回assignment_date，profile的确认历史、latest和student_evidence按event.revision附当时日期；个人知识证据、固定补练来源与个人/原卷报告展示当次日期，仍独立保留写入时间。旧确认无日期时不得套当前日期；待审日期不能进入已确认学情。班级统计和去重规则保持原定义，不以同一天当成同一次作答或推定独立性。

前端收件加选填日期，整卷加“作业日期”区域和独立修改窗口，保存说明为新待审版本。当前原卷有未保存修改时先保存再改日期。窗口初始无默认今天，清空合法；输入期间不自动保存；原生日历输入未完成时拒绝提交，不作为明确清空；提交前取消无写入。保存前绑定学生卷、版本、窗口和renderEpoch，阻止串卷；保存中的取消只取消窗口/后续刷新，已送达的本地保存可能完成，界面需明确这一点。来源过期或失败时不宣称成功；保存期间日期输入禁用，不丢后续编辑。

新增表是兼容性增量：Store初始化和恢复迁移只创建空表，绝不为旧卷填日期。恢复校验日期格式/纸卷归属/版本范围及主键、非空、外键约束，拒绝同版本重复日期；旧备份缺表可恢复为未知，篡改未来版本或非法日期备份拒绝。更新实际服务前通过现有完整备份接口备份，重启后9表摘要不变，新日期表0行。代码回退不会自动回退新增资料，需匹配备份核对。

不新增模型外发、不读取真实卷面作识别、不添加第三方依赖；心理档案与自动确认均排除。本轮验证仅用合成日期与资料，真实老师确认、实际作业日期、复测独立性和省时仍待试点。
