## 老师看到的变化

- **档案首屏先看问题。** 前置“需要关注的知识问题”，展示最多3项已有问题、出现过的作业份数和补练进展，可定位下方完整原题依据；全部知识组与历史保留。姓名与编号同显，待核对／缺材料仍可见；详细计数按需展开。标签线索不会冒充已核实关联，作业份数不称为独立作答次数。
- **核对首屏出现题目。** 将当前学生选卷合入身份区，移除重复全局工具条，压缩页头与间距。1366×768中第一题从约798像素前移到约568像素，题号、本次判定、题干和原答摘要可在固定操作条上方看到。身份、未知日期、登记范围未知和保存／确认规则保留。
- **班级统计说清楚。** 显示本次作业标题及同次编号，用“已收3名学生”“可判定2次作答中有1次错误”等中文说明；部分正确、待核对和缺材料单列。仅改变呈现，仍按现有单批次统计，不新增班级累计分析。
- **新作业表单减负。** 用“同次作业编号”解释原批次字段；日期与参考答案收进选填区，创建／取消按钮独立保留。编号仍需老师填写，日期不猜测，附件多选和各字段唯一性保持。选填区即使收起，无效日期也会拒绝创建并展开定位。
- **同名学生身份保持。** 证据弹窗增加学生编号；跨学生的补练／班级选卷显示姓名与编号，核对选卷仍限当前学生。

没有新增依赖或安装Skill，没有修改数据库／业务API、原有真实档案或模型配置，没有自动归档、外发、拖拽上传或EXE封装。

- Python首次受限运行有19错误／4失败，HTTP日志均出现本机回环`WinError 10013`，启动器相应显示UNREACHABLE。未改网络设置或测试断言；原命令在获工具许可、允许本机连接的环境下409项全部通过。首次日志`app/.qa-temp/ui-polish-python.log`保留。
