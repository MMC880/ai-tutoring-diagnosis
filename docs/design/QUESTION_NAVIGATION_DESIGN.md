# v0.26 整卷题目筛选与定位

目标：老师审核一份长卷时，先查看需要处理的题，按题号定位，减少来回滚动。沿用原整卷、逐题编辑器和确认规则，不新增自动判题、数据表或外发。

新增本卷题目工具条：全部、错误／部分正确、待核对、缺材料、有核对提示五类；可按题号、题干、知识点、题型或已录作答的文字查找，多词同时匹配，大小写/全半角统一，不猜同义词。提示包含未核清识读和按既有gradingConflict及核清状态判断的批改分歧。显示当前可见数／整卷总数及各类总数，零匹配明确显示；筛选不是已审核标记。

所有.question编辑行始终留在DOM，只用hidden隐藏；collectQuestions仍读取全部行。筛选、搜索、定位不保存、不清除脏状态、不勾确认；整卷确认仍包括隐藏题。工具条明确提示“当前只显示部分题目，保存/确认仍针对整卷”，待核对/缺材料/疑点总数不因隐藏变成0。全卷题号下拉可定位任意题，定位时先清除筛选和搜索，再滚动/聚焦对应题头；不修改答案或打开来源窗口。

筛选只在老师明确操作时重排显示。编辑题目后即时更新总数并提示“题目已修改，刷新筛选”，保留当前可见编辑行和焦点，避免判定改为正确时正在编辑的题突然消失。刷新筛选才重新应用；添加题目也保留新编辑行，并在刷新前提示。重新载入或切学生后默认显示全部，旧题号/筛选不带到另一卷。

上下文绑定当前卷ID、版本、renderEpoch和实际工具条节点。页面重建后旧按钮或状态不能影响新学生；没有异步导航请求，不写本地业务数据。模块question-navigation.js分离纯筛选与DOM操作，复用现有字段/判定规则。现有逐题识读、续录、教学引用和整卷导入保持原路径。

先测试搜索/分类/提示规则，再真实浏览器验证筛选、零结果、跳转隐藏题、未保存修改/隐藏题保存、添加题、确认仍检查隐藏分歧、切学生重置和窄屏。完整Python、原流程回归及一次独立审查后，备份/本机只读核验、白名单包和本地Git提交。真实老师省时和已确认学情仍待试点；心理档案不在范围。
