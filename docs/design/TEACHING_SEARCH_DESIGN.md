# v0.24 已审核知识查找与精确关联

老师要把原卷中的问题关联到准确的本地知识条目，才能可靠积累跨次问题。目前关联窗口只有完整下拉列表，资料多时难查，同名不同出处不易核对。沿用原本已审核目录与固定引用，补充搜索、按原资料筛选、分页和所选正文预览。

采用纯本地浏览器过滤：关键词按空白分词，多词同时匹配知识名称、题型、正文、资料标题、范围、出处或版本说明；大小写和全半角统一，不做语义猜测。每页20项，总数与页码可见；用户能访问全部命中，不静默截断。按资料ID筛选，重复标题不合并。未审核条目不进入原有服务端目录；来源有新待审稿时，原已审核版仍固定引用。

选择初始为空，变更关键词、资料或页码会清空选择和内容预览，禁用关联按钮；选中后展示知识、题型、正文、资料适用范围、版本、页码及原件链接。关联仍只填当前题的待审编辑器，不保存、不确认、不生成补练。保留原版知识/条目ID，不用搜索结果位置或同名文本代替来源。前端在关联前重新读所选固定已审核版本，并核对选中正文与归属；新批准版本不悄然代替用户选中的版本。

异步目录和来源回读必须绑定原学生卷、版本、题号、renderEpoch、reviewFlowEdits及当前窗口。切学生/页面、输入改动、打开另一个窗口或改变选择后，旧结果不回填、不覆盖新窗口。选择来源无法核实则保留窗口并提示，不产生写入。失败后可取消重开。

实现使用已有Python/SQLite和原生JS，不新增表、不新增接口、不改变目录审批/历史引用规则，不安装新依赖。新增teaching-catalog.js负责纯搜索与窗口状态，teaching-panel.js保持资料编辑和原件展示。范围限初中数学；心理、自动诊断、真实教师确认与模型传输不属于本轮。

完成标准：纯搜索测试先RED；浏览器验证筛选/同名隔离/分页全部可达/选项清空/内容转义/精确回填/迟到与回读失败保护；原教学库与其他受影响流程回归，完整389项Python；独立审查后修复重要项、备份并更新本机0.24，实际只读数据摘要不变；白名单交付包和本地Git提交。真实完整知识内容、教学效果和省时不能由合成用例代替。
