# v0.8 同题续录核对助手

2026-11-06，按用户持续授权推进既定跨照片/分题合并缺口。仅增加本地核对辅助，不改变后端转写、判分、归档或AI调用协议。

在可编辑的图片转写核对表（含失败后的本机人工表）每行提供“与本卷已录同题合并”。老师先核对题号，只有当前选中的学生/本卷/来源版本且有同题内容，才允许预览。不得按第一题回退；旧已应用记录不可合并。

预览分列本卷已录内容、本次转写与可编辑的最终题干/作答/识别备注。题干相同只留一次，不同题干使用【本次补充题干】保留两段；作答使用【本次续录】保留已有及本次文字；不推断先后推理是否正确。旧识别备注/补充与新备注去除完全相同项后合并。核清状态默认两段都核清才为真，老师可对照两页明确核清。不是错因诊断。

老师勾选“两段确属本卷同题并已核对”后，只把预览填入原转写核对表，不写盘、不发AI。清除原核对表的保存同意，仍须另行勾选并走现有保存转写接口，只得PENDING待审。原AI结果保留，老师修正表保存最终文本与source_ocr_id；整卷确认仍独立。预览编辑或原转写修改使旧同意失效；同一行本次填入后不能重复自动拼接。关闭预览可取消，不修改原卷。

来源切卷/切视图/改版本/未保存整卷修改，或预览期间原转写/题号已变，应拒绝填入。预览字段使用独立data属性，不混入原转写收集、整卷字段或其他行。最终沿用题干/答案12000、识别备注1500限制，超长不截断，让老师编辑后重确认。人工增行克隆须清理旧预览。

这是老师主动的文本合并助手，不自动认证两张照片的物理关系，不做语义去重或跨学生拼接。没有新增服务商/依赖/Schema。只有合成假接口、隔离库及本机只读验收，不以此宣称真实笔迹、整页可靠性或净省时通过。
