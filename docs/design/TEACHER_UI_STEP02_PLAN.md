- `app/web/workspace-navigation.js`：只负责既有页面分组、顶部三入口、设置入口、子导航和设置目录。不负责保存或改变学生/卷子身份。

- `app/web/index.html`、`app/server.py`静态白名单：加载新本机脚本，不增加业务API。
