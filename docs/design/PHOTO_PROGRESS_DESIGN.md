# v0.7 整卷照片处理清单

2026-11-06，沿既定照片主线补齐多照片操作。用户持续授权直接执行；这是实现选择，不新增业务判分或掌握规则。

在整卷审核的原件区列出当前学生当前卷的每张作业照片。只计PNG/JPEG作业附件，按附件顺序显示，参考答案和电子文件另在原件区处理。每张显示最近任务状态、来源版本，以及是否曾保存转写待审及该版本。最近失败不能抹掉先前保存记录；模型返回成功但未应用不算已保存，人工兜底保存与AI成功分开。照片全部有记录也不代表整卷齐全或教师确认。

只读接口 GET /api/papers/<id>/photo-progress：返回本卷/版本、三项计数、逐图document_id/filename/position/job_count/latest/saved。latest/saved仅含任务ID、状态、来源/应用版本、时间、目标题号；saved补充MODEL_REVIEW或MANUAL_FALLBACK。不得返回原图base64、请求体、题目、密钥、错误原文和其他学生资料。不受全局最近30条列表截断影响；旧无归属或损坏元数据忽略并计unlinked_jobs，不猜归属。无AI任务表时仍返回照片清单。

老师可直接“裁切这张”或查看本图最近任务/保存记录，复用现有框选、授权、失败恢复和审核。请求绑定本卷和明确附件，不能因附件已不在本卷而回退第一张。刷新清单不重绘或丢弃未保存整卷字段；异步返回不得插入已切换的学生页面。

不自动调用、重发、增版本、确认归档或合并续页。只显示曾保存的证据，不声称每张内容仍完整对应当前草稿。原卷历史/统计/补练不变，本轮仅合成及实际本机只读验证，真实笔迹质量/省时待试点。
