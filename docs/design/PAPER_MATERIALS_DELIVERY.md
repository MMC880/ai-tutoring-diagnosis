# v0.18 原卷补交与材料整理交付

日期2026-11-07。沿用老师逐生整卷审核与本地问题档案方向，补齐已建卷后的材料补交与显示顺序调整。当前本机0.18.0，进入整卷审核原件区点击“补交与整理附件”。

## 本次行为

老师核对学生、批次、标题和来源版本后，可一次选多份新照片/PDF/DOCX，选择新增文件用途、调整全部附件顺序，明确同意后保存。已有原件和用途不在该入口删除或替换；最多20附件，每个15MB。未加入清单的文件不能直接保存。

新增或排序生成原卷新待审版本，旧确认版本、旧题目判定及MISSING保留；无变化不增版本。后台严格检查学生/版本/同意和已有原件，重放旧版本不重复挂卷。没有自动识别、确认、归档学习事件或AI发送。

材料历史表保存首次0号原始锚点及每次变更前后元数据，meta独立登记发生过材料历史的卷。历史原件回看和学习去重依据事件当时附件；未审核补交不改变历史证据统计。旧格式备份可加表/登记列迁移，恢复拒绝已登记但整段缺失的历史、缺锚点、丢失变化前版本、跨卷或当前不一致的附件。

保存前取消不改卷；上传中关闭会停止后续挂卷，可能留下本机暂存文件。已经发出的明确同意保存不能靠关闭撤销。异步保存成功会失效页面缓存，重新进入时读取最新待审版本；同步前阻止旧缓存继续写入。已保存但页面读取失败会明确提示不要重复保存。挂卷失败可在同一窗口复用已上传ID重试，不自动重试、不承诺跨会话恢复暂存清单。
