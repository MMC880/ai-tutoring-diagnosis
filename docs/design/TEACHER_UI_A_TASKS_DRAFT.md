### 01 先选学生，再看已有档案

**交付行为：** 老师进入档案，从已有学生列表搜索并选择人，即可看到该生跨作业的已有档案。当前选卷不再决定档案学生。

**复用：** 已有学生列表、按学生标识读取档案、确认历史及知识/复测呈现。默认不新增学生管理系统或数据库表。

- [x] 首次进入未选择人时提示选择；空库能进入既有登记流程，不伪造学生。
- [x] 重名以稳定编号区分；所选学生有多份卷时都能追溯，未确认卷和已有确认分开。
- [x] A的请求迟到、旧弹窗、原题/报告读取均不能回填B；失败不把旧档案当作新结果。
- [x] 没有确认记录显示空状态；一次正确不删除旧问题，历史展示不写库。
- [x] 未保存编辑的切换经明确处理，取消保持原人和编辑；已存草稿不丢。

**对应验收：** A01—A05、A08、A10。**验证建议：** 用两个合成学生、同名不同编号、同生多卷、待审/空确认场景实际走页面；人为延迟公共读取响应检查旧结果；读取前后比较合成库历史。新行为测试先失败后最小实现，沿用已有档案回归。

**本项不做：** 三菜单全量换版、全新登记格式、班级名册、共用原题迁移、模型调用或封装。

### 02 收拢A方案三个主入口

**交付行为：** 顶部三入口与左侧学生列表形成正式A布局；设置和子页面承接旧功能。

**Blocked by：** 01。

- [x] 默认档案；没有学生/作业时有明确下一步，菜单不用研发术语。
- [x] 登记入口能到现有收件和整卷核对；补练/待办从档案内部进入。
- [x] AI、教学资料、备份/恢复、既有试点记录仍可达，原授权和恢复确认保留。
- [x] 旧链接打开正确子页面并归属正确主入口；选择/草稿/确认状态不会因重新渲染被静默清空。
- [x] 宽屏和窄屏主操作可达，不带入A/B/C对比条或虚构数据。

**对应验收：** A01、A03、A05、A11、A12。**验证建议：** 逐个旧入口检查可达与身份，截图看1440px和390px布局，复用已有导航/窗口相关回归。保留重要未核状态，不能用隐藏字段“通过”验收。

### 03 在登记入口完成真实保存与确认

**交付行为：** 老师选当前学生的一份作业，在简洁问题列表中核对，按需展开既有详细编辑，再保存和确认；回到档案可追溯本次真实写入。

**Blocked by：** 02。

- [x] 当前学生、作业、实际日期/未知、当前草稿版本清楚；用户明确选卷，不随意使用该生第一份卷。
- [x] 手动结果、照片辅助、原图、既有JSON草稿导入和逐题详情仍可用；未支持格式不展示成已实现。
- [x] 沿用服务端输入/分歧校验；空字段、待核和缺材料按真实状态，不通过简版界面绕过全卷确认要求。
- [x] 覆盖信息缺失时明确显示“登记范围未标明”，不新加仅错题确认，不将现有API能保存的题目列表冒称完整结果。
- [x] 保存只形成待审稿；明确确认后写入；改判保留原历史，重复确认不重复写入。
- [x] 选择其他学生/作业或导航前正确处理未保存修改；已存草稿重开能回读。

**对应验收：** A03—A07、A10。**验证建议：** 独立合成库从编辑到确认再回档案的完整路径，检查保存/确认/修订/重放，沿用整卷、材料、批改分歧和历史回归；不测试真实学生卷，不用前端假状态冒充写档成功。

### 04 独立选择统计范围，再下钻学生

**交付行为：** 在班级学情入口明确选择现有作业批次，查看当前可靠共性与证据，再打开对应学生档案。

**Blocked by：** 02。

- [ ] 明示当前仅本次作业统计，批次独立选择；切左侧学生不悄悄改范围。
- [ ] 未选批次提示选择，不静默统计全库；覆盖不明只报有依据的记录与人数，不显示整卷/全班正确率。
- [ ] 区分确认人数、已收材料份数、知识覆盖和问题人数；同生多份材料不冒充多名学生。
- [ ] 仅问题摘录、待核、缺材料和未知班级人数不产生虚假全班正确率。
- [ ] 无确认/空批次显示空状态，切范围的迟到结果不回填；原题依据仍有出处。
- [ ] 点击具体学生跳到该生及所选知识证据；返回时统计范围明确保留。

**对应验收：** A03、A08—A10、A12。**验证建议：** 用两个批次、同生重复材料、部分确认和缺页样例检查人数与上下文；不把原型三日选择器当成长班级跨次统计已经实现。

### 05 在学生档案继续补练与复测

**交付行为：** 老师从档案中已确认的来源问题继续现有补练流程，在学生内部查看题面、审批和真实复测历史。

**Blocked by：** 02。

- [ ] 打开正确学生与固定原题确认；来源不明或待审时如实提示，不猜历史。
- [ ] 讲解/基础/综合/迁移候选仍可审阅；只选一档不自动审批、发布或发完三档。
- [ ] 修改练习产生待审版本，旧版审批及迟交复测留在旧版，当前观察不被覆盖。
- [ ] 补练/复测/报告回到正确档案；实际完成条件未核不能称独立复测，一次正确只增加证据。
- [ ] AI仍走既有预览/授权；走查可用合成候选，不为本项强制调用真实模型。

**对应验收：** A03、A05、A08、A10—A12。**验证建议：** 两生两版练习和旧版迟交场景，沿用现有知识跟进、学习过程、待办及导出守卫检查。本项只衔接已有能力，不新增任意历史分组自动生成题目的业务模型。
