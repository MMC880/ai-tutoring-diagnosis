# 实际使用的海报生成提示词

生成方式：内置 ImageGen。用途：项目需求审阅。输出：jinxue-project-poster-v0.2.png。

生成一张高分辨率竖版中文产品方案海报，约3:4比例。用途为需求审阅，不是假装已经上线的产品。主题是山西初中数学作业诊断、学生学习成长档案和持续精准辅导。版式像专业教育科技产品的一页项目总览，强信息层级、清晰留白、排版规整、中文准确且大字易读。暖白纸感背景，深海军蓝标题，青绿色强调，少量琥珀色作为三档训练的最高层级点缀。细线图标、纸张和极少量正确数学符号可作装饰；不用人物照片，不做科幻机器人，不放虚构界面截图或图表数据。

准确排版以下中文内容，不能添加新的功能或夸大效果：

顶部小标：“产品方案预览 · v0.2”
主标题：“晋学智辅”
副标题：“山西初中数学 AI 作业诊断与精准辅导”

“学生问题知识库”
“保留证据与历史，追踪最新掌握情况”
“班级共性分析”
