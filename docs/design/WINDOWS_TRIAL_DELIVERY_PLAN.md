用户本轮明确选择“先整理说明书和封装方案，暂不开发”。本轮只增加文档及阅读版PDF，不改应用代码、不安装打包依赖、不构建EXE、不搬动学生资料。

## 首版交付目标

老师在Windows电脑上解压完整试用文件夹，双击“晋学智辅.exe”打开中文软件窗口，不用自行安装Python或输入本机网址。资料保存在独立本地目录，关闭后重新打开仍能找到记录。

推荐先交付便携文件夹，再根据试用决定安装包。便携版内部可以包含EXE和依赖文件，不能只拷走一个EXE。目标先按Windows10／11的64位电脑准备，兼容性以实际测试为准。

## 复用现有项目

沿用Python业务逻辑、HTML/CSS/JavaScript界面和SQLite＋本地文件；保留已经完成的三个入口、教师确认与历史追溯。新增桌面启动层和打包配置，不重写业务系统。

候选路线为**pywebview＋WebView2窗口、PyInstaller打包**。PakePlus可作为包装工具备选，但简单套网页壳不能同时解决当前Python后台、资料目录和退出管理，因此首轮不优先采用。Matt Pocock Skills负责研发工作流，与桌面包装工具没有职能冲突；本轮无需再安装Skill。

PyInstaller可携带解释器与依赖；WebView2需要检查目标机器的Runtime，缺失时给出明确处理方式，不静默安装系统组件。依据：[PyInstaller官方说明](https://pyinstaller.org/en/stable/operating-mode.html)、[pywebview打包指南](https://pywebview.flowrl.com/guide/freezing)、[微软WebView2分发说明](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution)。这些是选型依据，不是本项目已打包验证的证据。

|步骤|要做什么|通过的最低条件|
|---|---|---|
|1．桌面启动|建立隔离构建环境，锁定官方依赖版本；接入桌面窗口和自有后台生命周期|窗口可打开；重复启动有明确处理；关闭仅结束本程序自有后台；不自动确认学生记录|
|2．试用打包|携带Python、应用依赖和静态资源；排除密钥、真实档案、缓存和测试日志|生成真实Windows EXE及完整依赖目录；资料与程序分开；包内无真实学生资料或密钥|
|3．交付验证|用无Python开发环境的Windows机器或虚拟机验证；检查中文路径、保存重开、退出和备份恢复|目标环境实际跑通登记→待审→确认→档案；未测或失败项逐项列明，不拿开发机结果代替|
|4．老师试用|交付包、核心说明、版本标识和反馈表；先用合成材料演示|老师能完成最小流程；问题按版本记录、修复并回归；不承诺识图准确率和教学效果|
