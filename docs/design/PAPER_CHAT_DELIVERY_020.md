# 晋学智辅0.2.0试用交付

2026-11-09。基于2e591c1增量开发，用户已批准限定试卷引用、本地对话记录、教师核实后入档的范围。旧0.1.0及0.1.1包保留。

## 使用流程

解压完整`docs/delivery/windows-desktop-0.2.0/晋学智辅-Windows-x64-0.2.0.zip`，保留依赖文件夹，双击EXE。默认资料位置不变，未迁移旧库；升级前备份，退出旧版再开新版。

1. 设置→AI服务，填本机密钥、地址和模型，选择“保存并测试连接”，预览固定无学生资料请求并授权一次，查看结果。改设置后旧成功状态失效。
2. AI服务→试卷对话。明确选学生、勾选最多3份同一学生的作业。引用所勾卷子的全部已登记题干、原答与候选参考，可逐项查看；照片不会凭空成为文字。
3. 可另选最多3图。已有作业图支持框选与涂白；新上传图先本地保存、按整图加入，本入口暂不裁切新上传图，须先在本机去标识。实际PNG发送前完整预览。图片需当前模型与密钥的独立视觉验证；文字连通不代表视觉可用。
4. 核对实际文字、图像、目的地址后授权这一次。模型回答仅存本地对话记录，可同范围追问、导出英文`chat-任务编号.md`。切换学生或材料会清空追问关系。
5. 正式档案仍由老师通过既有登记核实与确认；没有把任意回答直接写入正式档案的按钮，不自动改判、标掌握或发布。

可输入服务商原模型ID，候选来自本机已用记录，不是完整服务商目录。换模型后重新测试。历史列表显示最近30任务；追问最多最近3轮/24000字符，超长最近回答明确标节选，完整原答仍留本机。

## 继承的修复

连接状态按会话记录；改设置、清密钥、恢复库或重启后不沿用成功。Windows备份先选择文件夹、取消不创建、英文文件名、复制后SHA-256校验；工作库和内部恢复副本仍在原资料目录，不等于搬库。

PNG/JPEG/WebP按实际编码读取，包括JPG后缀的WebP；统计、证据去重及教学资料恢复同步支持。原字节与大小/像素/完整性校验保留，失败提示具体文件名。截图D盘原文件不在本机，不能断言其实际格式或承诺真实问题已复现；旧数学样本JPEG可读，新增兼容验证用合成图片。
