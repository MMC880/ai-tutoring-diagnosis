# 老师工作台交互原型：审阅说明

用户已授权由我们继续制作下一阶段原型。本轮交付本地 HTML/CSS/JavaScript 的一次性交互样稿，使用虚构数据和已生成的合成照片；不是正式产品，不接模型、文件系统档案、会员或支付。

## 本轮回答的问题

老师能否以一生整卷为单位，在同一屏对照原图、识别结果与判断，纠正后明确确认，再查看个人记录和后续训练？重点审阅操作是否顺手，不用原型宣称准确率、权限隔离或持久化已实现。

## 视觉与页面

采用电脑端左右对照布局：安静的青墨色导航、浅灰工作区、白色纸张和清楚的状态标记。数学内容、疑点和教师操作优先，避免用大面积营销内容占据工作空间。布局和色彩为设计者提案，不作为用户已确认的品牌规范。

视觉参数：导航青墨 #183c40，工作区浅灰 #f2f5f6，纸张白 #ffffff，确认青绿 #14665f，错误暗红 #ac4651，待确认赭黄 #94691c。正文使用 Windows 上易读的微软雅黑 UI 系列，数学用 Cambria Math／Cambria，品牌单字使用楷体后备；不从外网下载字体。数学与状态文字保持主要视觉层级，颜色同时配文字。

```text
主导航 | 当前批次与确认进度
       | 学生列表 | 原始作答（独立缩放） | 逐题识别、判断依据、疑点
       |          |                    | 老师核对结果
       |          |                    | 整卷确认（固定可达）
```

- 材料导入：用对话框展示原卷、参考答案和作答的角色，原型只载入固定合成样例。
- 整卷审核：学生选择、原图缩放、逐题初判、识别修正、待核实错因和整卷确认。
- 学习档案：历史证据与当前表现同时显示，优势与薄弱处分别有依据；新确认在本页内追加。
- 班级共性：当前四题图片批次与既有十人六题模拟卷分别显示，不混题号、人数和复测。
- 补练复测：三档供选择，教师审稿后仅批准所选题目；模拟复测增加证据，保留旧错题。

## 关键交互约定

1. 原图不随识别修改而变化；识别文本、判题结果和错因确认分开。
2. 整卷确认需人工核对并确认具体范围；审核前不写入演示档案。部分正确、待确认、缺失分别显示。
3. 所有写入、批准、复测和导出都明确为界面演示。状态仅存在页面内存，刷新恢复初始值，没有真实归档或文件导出。
4. 一次新题答对不判掌握；原卷统计不被复测改写。
5. 本轮导出提供 Word／PDF／取消选择与预览，不生成假扩展名文件或假装真实导出。

## 运行与范围

双击 prototype/index.html 即可打开，无框架、外部脚本、网络字体或接口调用。所有图片放在本地相对路径，移动整个目录仍可查看。只检查关键交互和视觉，不建立应用测试套件，不复制旧项目程序。

2026-11-05 实际交付：prototype/ 下已制作 HTML、CSS、JavaScript 和本地合成图片。已有18项浏览器关键交互检查与七张预览截图；通过仅针对本次原型，没有真实数据或持久化验证。正式产品仍待原型审阅及后续方案确认。

本轮以已确认的左右审核布局为默认，不重新开启技术架构或多个界面方案的访谈。原型确认后再规划正式应用；真实档案及第三方模型边界另行落实。
