## 出问题时如何恢复

先在项目根目录检查：

```powershell
git status --short
git log --oneline --decorate -10
git diff
git diff --cached
git diff baseline-v0.16.0-20261107 -- app
```

先定位发生问题的改动并保护未提交工作，优先做最小修复提交；确定某个已有提交有问题时，可在保护现场后使用 `git revert <问题提交>`，保留完整历史。

要对照基线运行代码，可以在项目外选一个尚不存在的新目录，用本地 `git worktree add --detach <新目录> baseline-v0.16.0-20261107` 检出副本。先检查依赖，使用独立资料目录和空闲端口；不要让不同版本同时操作当前学生库。该操作不覆盖当前工作目录。

从历史恢复单个文件前，先保存该文件的当前修改，并核实目标路径与版本。禁止用整项目删除、整体覆盖、`reset --hard`、`clean -fd` 或全目录恢复替代分析。Git 不能恢复从未提交的文件或已忽略的学生数据；资料恢复仍使用应用的独立备份机制，并核对代码/数据版本兼容性。
