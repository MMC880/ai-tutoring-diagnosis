# v0.10 每生本地档案交付

日期：2026-11-06。对应7步计划第2步的软件能力。真实两生归属、真实教师确认与课堂省时仍待试点，不把合成记录代写真实档案。

## 本次交付

- 可在个人学习档案中按学生选择；摘要、当前待补清单与同类问题使用同一去重口径，未标知识点记录也纳入摘要。
- 最新确认与完整历史分别保留。待审修订不替换已确认内容，复测继续单列；不自动认定长期知识缺失或掌握。
- 从原题记录打开只读历史窗口，回看当次原答、原判、原批注、AI候选、核对说明、知识点和确认时间。
- 可查看同题最近确认或回当前原卷；窗口明确区分历史、此卷最近确认和待审修订，附件是本卷原件集合，不捏造本题页码定位。
- 历史GET同时约束事件、学生及所属卷。切换学生、离开后切回同一学生或发出较新请求，均使旧证据响应失效；材料文字转义，不执行内容中的指令。
- 作业照片/PDF/DOCX完全相同的文件哈希集合、同题号按最后确认结果保守去重；参考资料不参与来源判重，不同学生独立计算，完整历史不删除。

这不是多机构权限系统、笔迹身份认证或完整知识库。重拍/压缩、不同格式、部分重叠页集不保证自动去重；空白原卷复用需作为参考附件，实际作答应单独上传。当前时间为确认写入时间，不是自动认证出的考试日期。
