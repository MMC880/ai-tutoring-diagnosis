# 晋学智辅 Windows试用版 0.2.1

解压完整文件夹，双击“晋学智辅.exe”。请把EXE和旁边的_internal文件夹一起保留，不要只拷走一个EXE。

第一次打开为空档案，不包含真实学生资料，也没有预填AI密钥。适用Windows10／11的64位电脑，老师无需另装Python；电脑需要Microsoft Edge WebView2 Runtime及.NET Framework 4.6.2或更高版本。缺少组件时按中文提示从微软官网安装，本软件不静默安装系统组件。

## 三个主要入口

- 学生档案：先选学生，查看已有知识问题、历史依据与复测进展。
- 登记作业：选择学生与作业，导入多份照片、PDF或DOCX，登记老师批改的结果。保存只是待审，老师明确确认后才写入档案。
- 班级学情：查看当前作业批次中已经确认的共性问题，待核对和缺材料单列。

AI服务、教学资料和备份在设置中。核心是积累学生的问题与后续变化；老师仍负责批改、教学与确认。单次错误不认定长期薄弱，一次答对不等于掌握。不建立心理档案。

## 本次试用更新

- AI服务可“保存并测试连接”：预览固定测试并授权后显示本次文字连接结果。修改地址、模型或密钥后须重新测试；文字连通不代表图片支持。
- 备份先弹出文件夹选择，取消不创建；选定后保存并校验英文backup-时间-编号.zip。建议选D:/JinxueBackups。日常资料和内部恢复副本仍在资料目录，不是自动搬库。
- 照片按实际PNG/JPEG/WebP读取，包括JPG后缀的WebP；仍有格式和大小限制。出错提示具体文件名。
- 设置中新增“试卷对话”：选学生、勾选本次引用的卷子和照片、填写问题，预览后才发送。可切换模型；实际可用模型以所接服务支持为准。
- 回答和追问保存在本地，可导出英文文件名Markdown。回答属于AI建议，老师审核后通过已有登记流程记录确认的事实，不自动写正式档案。未授权材料不会因打开对话入口自动发送。
- 图片仍需本次服务和模型的独立视觉验证。照片预览要核对身份遮挡和内容；不清楚的材料不要直接发送。

## 资料放在哪里

默认资料位于 %LOCALAPPDATA%\JinxueZhifu\data。可在设置的本地资料与备份中核对实际位置。

资料不在程序文件夹中。换新版程序不会自动搬迁或删除资料；请先在软件内备份。已有开发版或WorkBuddy资料不会自动导入，需要另行确认迁移。

关闭窗口会提示退出；未保存的输入不会保留。已保存待审稿和确认档案会保留。正在保存或处理时请等待完成。同一资料目录只允许一个实例，重复打开会提示回到原窗口。

## AI和导出

需要使用AI时，在本机设置中填写服务地址、模型和密钥，按每次操作预览并确认拟发送内容。本地软件不等于模型完全离线。不要把密钥发到聊天、截图或反馈表。

Word导出使用保存文件对话框；PDF走打印页，可在系统浏览器里打印或另存为PDF。复杂公式、几何图和分页仍需老师核对。

本机已验证合成归档、复测、Word文件结构和打印页内容；原生保存对话框、实际打印及另一台无Python的干净电脑尚待实测，不能据此承诺所有电脑均已兼容。

当前是Windows x64试用交付；没有安卓安装包、家长端或会员收费。拖拽导入、跨次班级累计分析尚未加入，当前可以一次选择多个文件。
