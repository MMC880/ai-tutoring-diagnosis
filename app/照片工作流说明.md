# 照片作业：从原件到待审卷

v0.4，2026-11-05。本版仍为老师操作的单机试用程序，心理档案始终排除。

## 建议操作

1. “收一份作业”，选对学生与批次，上传已经完成的PNG/JPEG作业。先保存草稿。参考答案另附，不把参考当学生笔迹。
2. 在“AI服务”保存本机会话密钥，预览并授权合成数字图验证。数字读对只说明当前会话能处理这张图，不证明数学或真实手写准确率。
3. 回本卷点“裁切并转写图片”，先选一道题，包含题干及学生步骤。姓名、学校等区域涂白；原件保留本地，裁切图重新编码并去除元数据。
4. 检查将要发送的PNG、接口地址和模型，授权这一次发送。没有自动重试；一次失败不代表没有费用。
5. 对照原图核对题号、题干及学生原作答。写错的负号、漏写条件等必须如实保留。无法辨认就保留识别疑点，不能猜成学生的错误。
6. 勾选核对说明，保存到新待审卷。只合并本次题号，其他题保留；同号续页需先人工合并。未核清题继续PENDING，不能送文字批改。
7. 对已核清题按需点“AI辅助核对”，预览必要文字后授权。返回建议须主动放入新待审版本，再由真实老师核对整卷并确认。转写核对不等于整卷归档或学生发布批准。
8. 按需导出教师Word核对报告；疑点单独列示。学生练习需另行审核当前版本，不能把带答案的教师报告当学生版。

## 失败时继续工作

图片任务为 INVALID_RESULT、UNKNOWN 或 FAILED，可点“在本机人工整理这张图（不调用AI）”。不用密钥，不产生新调用；对照区域图增减题行、填写转写和疑点，再保存待审。原任务状态、返回用量和原始记录不改，人工整理来源另存。不反复点发送，不把人工输入冒充识别成功。

UNKNOWN 意味着结果与费用待核查。先查服务记录／账单。切小区域新建任务也可能产生新费用，不能算免费重试。

## 逐题继续处理

已录入题号的卷，可在目标题下点“重新识别这题”。裁切页显示所选题号，默认不选择区域；框入该题题干和学生步骤，再预览、授权。自由区域模式仍用于初次转写或多题。

单题模式只允许更新目标题。模型若把Q02读成Q01，系统保留原读号并新增识别疑点；请对照原图核对题号、改为正确目标，重新勾选核对说明后保存，不能顺带改其他题。原AI读号和人工修正分别留存。失败后的本机人工表同样只接目标一题。

失败页面的“改为分题框选”会回到任务所属学生这份卷的当前版本，重新选区域，不自动发送，不复用旧任务授权。若当前另有未保存修改，先保存再切换。旧记录没有完整原因时不猜测；之后的新调用记录可区分有证据的超时、截断及格式问题。

## 这次实际验证到哪

v0.4本轮没有新增真实模型调用。140项自动检查、16项照片完整性浏览器检查使用合成／假服务；下表真实API证据来自此前版本，不能据新增功能把整页识别改记通过。

| 场景 | 实际结果 |
| --- | --- |
| 合成随机数字图 | 三次真实调用成功，仅为会话能力探测 |
| 合成数学整页 | 历史一次格式不合格、一次结果未知；新增诊断一次读取超时、费用未知；整页未通过 |
| 同页第一题裁切图 | 真实转写成功，学生两个负号原样保留 |
| 第一题后续文字诊断 | 返回错误判断及正确答案，保存V4待审；没有归档 |
| 整页失败后本机人工整理 | 已在本地页面验证，无新外发，原失败状态保留 |
| 学生真实手写、实际课堂省时 | 未验证 |

当前试用数据的“虚构学生 · 照片接口验证”有四题，V4仍未确认；第3题的1/l字形疑点保留。模拟录入不是真人教师签字，不自动形成长期薄弱标签。

PDF／Word文字可辅助收件核对，本版不把PDF扫描页自动转为图片批处理。复杂分式、根式、几何图与公式排版仍应核对原件。Word支持可编辑OMML文本及简单上标，不是完整LaTeX渲染器；PDF通过浏览器打印页另存，实际打印未验收。

## 检查整页是否漏题

自由区域模式可填写“本次图片应有题号”，如 `Q01, Q02, Q03, Q04`，只填写此次区域确实应包含的题。清单留在本地，不会附到模型请求中。单题模式与该清单互斥。

假设只识别出前三题，核对页会列出漏识别Q04。保存后Q04继续保留在整卷，标PENDING和未核清；已有原题／笔迹保留并注明需要再核对，没有的留空，不能用参考答案补成学生作答，也不当作学生不会。清单外读号需对照原件修正，原AI读号保留。

没有清单时，页面显示“尚未核验题数完整性”。格式正确或读出三题并不证明照片里只有三题。老师仍需对照原图整卷审核。

## 可选图片分段接收

在AI服务设置勾选“图片分段接收”，保存后重新做图片会话验证。只改变图片探测／转写的接收方式；默认关闭，不切换模型，不自动重试，渠道实际兼容性待实测。预览会标明接收方式以及本机学生、卷和版本，身份与整库不发送。

仅完整结束后才解析最终照录文字，不保存模型思考过程或执行工具。中断则保持UNKNOWN，保留已收到的合法用量，不能把部分JSON应用。现有网络阻塞空闲限制45秒；分段接收阶段在网络块之间检查120秒总耗时，末次阻塞可能再等待45秒，不包含前置连接／响应头时间，不能当作整次请求精确限时承诺。界面验证使用假服务，不能证明真实延迟已改善。
