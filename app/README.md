## 启动

双击 `启动.cmd`。它检查已有 Python 3.12+ 和依赖，复用同目录、同资料库的已运行服务；找不到可用环境或端口冲突时停止并提示，不自动安装、不结束其他进程。具体见 `启动与检查说明.md`。也可在本目录手动以前台方式运行：

```powershell
python server.py --open
```

默认地址 `http://127.0.0.1:8765`。双击启动采用后台服务，关闭启动窗口或浏览器不会停止服务；上述手动前台方式可用 Ctrl+C 停止。只能在这台电脑使用，请勿把服务暴露到公网。

所需库：python-docx、pypdf、Pillow。若提示缺依赖，可自行选择在独立 Python 环境安装 `requirements.txt`；启动器不偷偷安装或更改全局环境。

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python server.py --open
```

默认数据在本目录 `.local-data/`。自选数据目录／端口：

```powershell
python server.py --data-dir "E:\MyJinxueData" --port 8766 --open
```

## 老师怎样试用

1. 第一次先点“试一份四题合成样例”，它的转写与判断是预设的，不证明 OCR 能力。
2. 或点“收一份作业”，填写唯一学生编号、称呼、作业批次，附上图片、PDF、Word；老师参考答案可以另附。图片可按需点击“裁切并转写图片”，不会在上传时自动外发。
3. 对照原件逐题录入、修改，或导入结构化 JSON 草稿。PDF/Word 文字提取只辅助核对，不能代表公式识别正确。
4. 保存草稿，再勾选整卷确认。修改已确认卷会生成新版本，必须重新确认；旧事件保留，重复确认不增加事件。
5. 在“个人学习档案”查看原题历史、最新表现和复测；在“班级共性问题”查看当前作业批次。不同卷用不同批次，同批次同学生只能一份卷。
6. 从已确认错误／部分正确原题建立一档补练，老师可以自行编题，也可逐次授权AI拟讲解与三档候选后选择一档放入草稿。顶点式有三档自编模板，其他内容不要套用该模板。保存后审批学生版，再按需导出或记录复测。版本选择可查看只读旧题面；已批准旧版能处理对应迟交，旧审批不授权新题面。
7. 复测注明独立／有提示／条件待核实，由老师判定并确认。复测单列，一次答对不会自动变为“掌握”。
8. “本地资料管理”创建备份并可下载。恢复须明确输入“恢复”，系统先保留恢复前备份；恢复会回到所选时点。

## 导入草稿格式

粘贴以下对象或直接粘贴 questions 数组；只导入草稿，不自动归档：

```json
{"questions":[{"id":"Q01","stem":"求 y=(x+1)²−4 的顶点。","answer":"(1,-4)","correct_answer":"(-1,-4)","result":"INCORRECT","knowledge":"二次函数·顶点式","cause":"待核实"}]}
```

状态：CORRECT 正确、INCORRECT 错误、PARTIAL 部分正确、PENDING 待核对、MISSING 缺材料。后两者不记为不会；二元错误率只以正确＋错误为分母。部分正确的实际判分口径还需与老师确定。

## Word 与 PDF

按需选择一种格式或取消。Word 为真实 DOCX，A4、四边2cm，使用原生可编辑 OMML 文本与简单上标；不是通用 LaTeX/复杂公式转换器。复杂分式、根式与几何图必须对照原件检查。

PDF 通过本地专用打印页，在浏览器选择“另存为 PDF”；不是后台直接下载 PDF。先检查公式和分页。学生补练版须审批当前版本，不包含独立的教师答案／讲解字段；老师仍须检查题面是否自行混入答案。

## 数据与安全边界

- 身份称呼、完整历史和原附件留在资料目录。文字AI只发送本次预览的题目、作答与核对参考，不附完整档案；图片须另走裁切、遮挡、预览和逐次授权通道，只发送重新编码的PNG。Word/PDF原件不外发。题目自身夹带身份文字时，老师应删去或遮挡；系统不宣称已自动去标识。
- 没有云同步、会员支付或多人权限。接口预设为用户指定的服务与模型，API Key只在本机网页输入，进程内存使用，不保存到数据库/日志/备份；重启或恢复后需要重新输入。
- 仅回环监听、限制 Host/Origin、写入令牌与事务控制，是单机试用防护，不能代替正式权限、真实资料隔离或商业上线验收。
- 附件限制 PNG/JPEG/PDF/DOCX，每个15MB；不执行导入内容。宏 Word、加密 PDF、超大文档不支持。
- 备份含个人资料且未加密；由电脑使用者保护文件权限。不要将整个资料目录或备份交给中转站／模型。
- 已验证的合成流程不代表真实手写准确率、完整初中知识库或教师净省时已经达标。这些须用获准材料实测。
- 本版是自有本地试用程序；WorkBuddy 既有工作流包和62条历史记录没有迁移或修改。

## 文字AI接入

打开本机 `http://127.0.0.1:8765/#ai`。先保存本机密钥，预览并授权一次无学生资料的连通测试。成功后，在整卷审核点“AI辅助核对”，减少到必要题目、清除材料里的身份文字，再预览实际内容与目的地址，明确允许这一次发送。

返回结果不会改卷，选择“仅放入待审草稿”后才生成新版本；原题、原作答和旧确认历史保留，老师仍须逐题核对并整卷确认。图片先转写再核对，未核清的字形疑点不能记对错、不能送文字批改。不用AI自动出补练，不自动发给学生。

配置与错误处理详见 `AI接入说明.md`。默认直接HTTPS，不改变或自动使用系统代理设置。已有指定服务真实文字与合成单题图片请求证据；真实学生手写、完整初中题型可靠性与教师省时仍待验证。

## 备份与外部调用

备份恢复不能撤销已经发生的外部用量。`ai-outbound-ledger.jsonl` 保存不含密钥、题目或姓名的发送凭据，外发前写入并刷盘；备份带上凭据，恢复只合并、不回退。恢复旧备份后，已尝试发送的同一任务会标“待核查”，不会重新调用。不要删除这个文件后重试；损坏时系统会阻止新调用。

这只能使用本机或备份中已有的证据，不能从一份过早的旧备份推断另一台机器后来发生的调用。换机应携带最新资料与发送凭据；Token/墨点对账仍以上游实际账单为准。

旧系统没有保留、也没有复测快照佐证的补练历史不能恢复；升级只保留实际可证实的版本，不编造旧审批。
