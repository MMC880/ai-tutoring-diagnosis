# 班级共性知识问题使用说明

1. 从批次收件或整卷审核选中本次作业，再打开“班级共性问题”。统计范围是当前批次，不代表固定名册或全年班级。
2. 先看“本批知识共性”。同一学生多道错题只计一名涉及学生；错误和部分正确属于待补齐，正确、待核对、缺材料分别显示。草稿和复测不混入原卷确认统计。
3. 已关联记录按老师审核的稳定知识条目整理；同条目跨版本、名称和题型一起查看。同名不同条目、无条目标签线索分开，不自动推断同义知识。
4. 展开逐生原题证据，对照原答、当次教师批注和原件。待审修订不会替换旧确认，窗口会注明历史或待审状态；这里不改判或批准练习。
5. 点击“查看该学生档案”核对这个孩子的跨次问题和补练复测；一次作业涉及多名学生只是集中核对线索，不直接判断长期薄弱或掌握。
6. 要修正判定或知识关联，回该学生当前原卷，保存后重新审核确认，再刷新本批摘要。原确认仍保留。

老师仍需核实知识归类、原题证据与实际教学安排。本页不自动生成全班讲稿或向学生发题，身份和完整记录留在本机，不自动发送给外部模型。页面读取出错可重试；期间换批次、换页面或开新窗口会取消旧的查看/跳转。
