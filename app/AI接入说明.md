# 在本机接入你的AI服务

已预置你提供的地址与模型名：

- Base URL：`https://discovery-api.intern-ai.org.cn/v1`
- 模型：`deepseek-v4.1-flash-1017`
- 协议：OpenAI兼容 Chat Completions，实际请求路径为 `/v1/chat/completions`。

依据：[书生官方接入说明](https://discovery.intern-ai.org.cn/token-plan/home?dockey=07-agent-tools.md)。指定模型在你的账号下是否可用、是否支持图片，以及当前计费，须以真实账号实测和服务商信息为准；不从模型系列能力推断渠道能力。没有自动替换模型。

## 第一次只测连通，不用学生资料

1. 启动本地服务，打开 `http://127.0.0.1:8765/#ai`。
2. 在本机密码框输入API Key，点“保存本机设置”。这一步不调用模型；不要把Key发到聊天、文档或截图里。
3. 点“预览一次无学生资料的连通测试”。确认地址和固定测试内容，再勾选本次授权发送。测试可能使用少量额度，不预估金额。
4. 出现“本次固定文字请求返回合格JSON”才说明这次文字请求完成。它不证明手写识别、数学批改可靠性、真实数据隔离或商业使用要求已通过。

密钥仅留本次Python服务进程内存，不回显、不写数据库/日志/备份；服务重启或恢复资料后须重新输入。清除会话密钥后后续任务不能发送。页面设置已填不等于真实连通成功。

## 再测一份合成文字作业

1. 选择合成样例，保持虚构身份，在“整卷审核”保存草稿。
2. 点“AI辅助核对”。只保留本次必要的题目、学生原作答与参考答案；删去题面中夹带的姓名等信息。当前不上传原图、PDF或Word，不附个人档案、班级摘要或身份映射。
3. 生成外发预览仍不调用。核对实际文字、目的地址、模型和输出上限，再勾选并发送一次。
4. AI返回只是建议。先看题号、答案依据和知识点，再选“仅放入待审草稿”；这会生成新的待审卷版本，不覆盖原作答，不写确认事件。
5. 老师继续核对原件，修改不妥建议，再勾选整卷确认。错因默认保留“待核实”，不能据此直接判定长期薄弱或心理状态。

## 各状态如何处理

| 状态 | 含义与下一步 |
| --- | --- |
| 已预览，未发送 | 只做本地准备；未输入密钥／未授权时不能发送 |
| 发送中 | 请等待，不重复点击；网络单次阻塞空闲限制45秒，图片分段另有块间总耗时检查；不自动重试 |
| 已返回，未应用 | 只是候选建议，可核对后放入待审草稿；不是老师审核通过 |
| 返回格式不合格 | 可能已发生用量；题号、题数或JSON不合格，不会自动写档或再次请求 |
| 接口返回失败 | 会显示HTTP错误码；先核对账号密钥、模型、额度与接口。密钥和上游原始错误正文不会写进错误记录 |
| 调用结果待核查 | 超时／中断／恢复后存在发送凭据，是否发生用量不能确定；先查上游账单，不重发同一任务 |
| 已放入待审草稿 | 回到整卷审核，继续由老师确认；不能直接给学生发布 |

用量只记录服务返回的数值，未返回就写未知。即使模型输出格式不合格，已有usage也会保留。不把Token直接换算成墨点；官方结算说明见[模型与计费文档](https://discovery.intern-ai.org.cn/token-plan/home?dockey=04-model-limits-and-pricing.md&tabIndex=3)。

## 当前范围

v0.3 已接文字辅助核对，以及另行授权的图片区域转写。先在服务页验证随机数字图，再在本卷裁切遮挡、预览实际PNG、授权一次发送。模型只转写，老师核对后存新待审版本，之后才能选择文字诊断。未解决的识别疑点会被拦截，不作为学生错因。图片能力仅绑定当前密钥／配置会话，变更或重启后重验。

图片调用格式不合格、失败或结果未知时，可“在本机人工整理这张图（不调用AI）”。无需密钥，不新增外发；原失败状态和已返回用量保留，人工转写不会标成AI成功。只保存待审，不能代替真实老师批准。

v0.3.1支持已录题号的单题目标模式：目标题号只作本地约束，不发送身份信息，读错题号需人工核对修正。新调用保存简短原因及耗时；仅捕获到TimeoutError（或明确包装的TimeoutError）才标超时，其他UNKNOWN不猜原因。恢复或重启会清除会话密钥和图片验证，不把旧数字图成功当作新会话授权。

2026-11-05 实际结果：固定文字与四题合成文字核对已成功；随机数字图三次成功；单题裁切图转写和其后文字诊断成功。两次整页图请求分别 INVALID_RESULT、UNKNOWN，不能声称整页识别通过。后一次具体异常种类未留证，不能回推一定是超时。合成图片相关已返回 usage 合计4986 Token，另有一次UNKNOWN用量未知；此前两次文字请求1236 Token另列，计费以上游账单为准。

v0.3.1诊断补记：另建一次合成整页任务，52.08秒后捕获读取TimeoutError，仍为UNKNOWN且usage未知。没有应用或重发，原卷V4与0正式确认事件不变。已返回Token合计未增加，目前上述图片相关另有两次UNKNOWN用量未知；不能用这次原因回填之前UNKNOWN。界面和规则改进之后仅做隔离假AI检查，没有继续消耗真实模型调用。

默认自动检查使用隔离合成资料与假接口，以上真实API结果另有独立记录。所有材料均为合成数据；真实学生手写、数学判分可靠性、复杂公式与净省时仍需真实材料验收。未做完整题库或AI自动出补练。后续商业软件是否适用当前账号、模型服务及计费方式，另行核实，不自动售卖或转售该服务。

## v0.4图片分段与清单

“图片分段接收”默认关闭，只作用于图片探测和转写。开启会发送stream=true及用量请求选项，配置指纹改变，需要重新验证图片会话；旧外发预览不能沿用。实际格式参照[DeepSeek官方Chat Completions说明](https://api-docs.deepseek.com/zh-cn/api/create-chat-completion/)，不据此推断书生指定渠道一定兼容；本轮未实际调用验证。

按响应Content-Type接收SSE或普通完整JSON；不另发降级请求。只收最终content，不保存reasoning_content或执行工具。完整终止后才进入原有JSON／题号校验；流中断或不完整为UNKNOWN，保留已知合法usage，后续空字段不能清除先前数值。响应上限1MB、单行256KB、最终文字100000字符；接收块之间检查120秒，末次阻塞仍受45秒空闲限制，连接／响应头时间另计。

本地应有题号清单用于核对漏题，不进入请求body。清单齐全只表示题号对应，不表示笔迹或数学正确。漏题PENDING及识别疑点未核清时，不能记对错或送文字批改；历史原题、原作答和完整备注保留。


## v0.6 单题讲解与三级练习候选

“针对性补练”中可从已确认错误／部分正确原题拟辅导候选。仅预览单题必要文字，勾选后本次发送；六步教案及三档题目均需老师核验。老师选一档仅建练习草稿，再单独审批学生版，不把辅导结果写成原卷新判断。换档重新确认，同档重复返回原练习而不覆盖老师修改。失败或格式不合格不补造结果、不重试；真实服务出题质量本轮未测。详见“辅导候选使用说明.md”。
