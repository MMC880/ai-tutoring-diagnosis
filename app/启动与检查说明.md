# 老师启动与环境检查

本版是本机单用户试用程序。先解压到独立文件夹，再双击 `启动.cmd`；打开的网页仍是 `http://127.0.0.1:8765`。浏览器中可以继续整卷核对、查学生问题档案和安排补练。

启动器先找这台电脑已经存在、依赖齐全的 Python 3.12+。查找顺序为本目录 `.venv`、PATH 中的 Python、Python Launcher、当前用户已存在的 Codex 内置运行时。它不下载 Python、不安装库、不修改 PATH、注册表或 PowerShell 执行策略。没有可用环境时会提示按 README 准备独立环境。

如已明确指定 `JINXUE_PYTHON`，只用该解释器；指定错误时提示失败，不偷偷切换。该变量只需要设为已有 `python.exe` 的完整路径，不是密钥。

## 再次打开会发生什么

- 同一个程序目录、同一个资料目录的服务正在运行：直接复用，重新打开网页。
- 端口被其他程序占用，或无法确定服务归属：停止并提示，不结束其他程序，不自动换端口。
- 旧版本没有服务归属接口：也会提示冲突，不能冒充可复用；请先备份，由维护者核对并关闭旧服务后启动新版。
- 第一次启动：本机创建资料目录和服务日志，等待服务就绪再打开网页。

双击启动的是后台服务，关闭浏览器或启动提示窗口不会结束服务，也不会因此清除会话密钥。不要把“关网页”当成“停止服务”。退出/重启由维护者核对服务所属目录、资料目录及对应进程后处理，不能按 `python.exe` 名称全部结束。

若需要在前台运行并可直接用 Ctrl+C 停止，使用 README 的 `python server.py --open`。后台和前台不能同时占用同一资料目录。

## 只检查，不开始处理作业

在本目录 PowerShell 中执行：

```powershell
.\启动.cmd --check --no-browser
```

输出环境与本机服务的 JSON 检查结果。不启动服务、不创建资料库、不打开浏览器、不读取学生档案内容或密钥、不调用外部模型。依赖导入不代表图片识别、公式质量或真实课堂流程已通过。

可指定另一个资料目录和端口检查：

```powershell
.\启动.cmd --check --port 8766 --data-dir "E:\晋学资料\数学试点"
```

`--check` 成功退出码为 0；不可用环境、冲突或检查失败为 1。`FREE` 表示端口当前无服务，`OWN` 表示匹配本程序和资料目录，`CONFLICT` 表示其他服务/身份不明，`UNREACHABLE` 表示网络检查未完成。检查失败不作“端口空闲”的推断。

启动失败可查看本次资料目录下 `launcher-service.log`；不要把整个学生资料目录或备份发给外部接口。默认目录是 `.local-data`。程序启动日志只记录启动信息，既有密钥不写入日志。
