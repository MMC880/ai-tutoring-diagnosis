# 数学错题复盘

本技能是工具链验证样例，尚未完成教学内容验收。

## 操作流程

1. 核对输入是否包含原题、学生原答和老师确认结果；没有的内容标为待确认。
2. 引用题号或图片位置，保留原答，不把红笔订正当成学生首次作答。
3. 提出主要知识点和支持依据；单次错误仅记录本次表现，不认定长期薄弱。
4. 根据已确认事实提出一条复习建议，明确建议与已经发生的补习不同。
5. 若要写入正式档案或发布练习，先交给老师确认；一次答对不认定掌握。

## 输出

使用中文输出：事实依据、知识点候选、复习建议、待确认事项。没有证据时不补造结论。
禁止心理画像、人格标签；本技能不授权外发学生身份或完整档案。
