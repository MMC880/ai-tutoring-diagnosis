# 晋学智辅2.0：自己测试手册

适用版本：2.0.0-preview.1。日期：2026年11月11日。

先打开 USER_GUIDE.txt，照着操作；这份手册只负责记录结果。在 [ ] 中写√表示成功，写×表示失败，不确定写“待确认”。不会操作也算需要记录的问题。

## 准备

- 使用虚构学生“测试甲”、练习班级“九年级一班”，避免把练习记录混进真实学生档案。
- 准备一张不含个人信息的图片。测试错题3、5、8只是模拟老师登记，不验证AI批改准确率。
- 第一轮不用密钥，不需要花模型费用。先做测试1—5，成功后就可以结束。
- 如果以前做过同样测试，已有记录或重复提示可能正常，不要要求系统必须再增加一条。

## 测试1：能打开

操作：完整解压，双击 JinxueZhifu.exe。

成功应看到：“本地学习档案工作台”；点击“打开 AI Agent”后出现小聊天窗口。

- [ ] 大窗口能打开。
- [ ] 小窗口能打开。

如果失败，记录报错，不必继续。

## 测试2：能收一张图片并正式保存

操作：小窗口选数学，点“选择文件”添加一张图片，然后发送：

> 这是九年级一班学生测试甲今天的数学作业，帮我归档。错题是第3、5、8题。

首次新建学生时，核对后点“新建档案并继续归档”。

成功应看到：以“已归档并回读”开头的结果，学生、学科、材料数和错题号都与输入一致。

- [ ] 收到的文件名是我选的那张图。
- [ ] 已归档到测试甲的数学记录，班级是九年级一班。
- [ ] 文件数1，错题号3、5、8。
- [ ] 如有学生确认卡，我能看懂并选对。

仅有“已接收”或“已暂存”，不能勾“已归档”。“回读”表示软件保存后又检查了一遍。

## 测试3：能查回来

操作：在小窗口问“学生测试甲最近一个月错过哪些题？”；再在大窗口选择数学、查找测试甲、刷新作业记录，选这份作业。

成功应看到：这份作业和第3、5、8题。日期待补的材料不要求出现在本月统计，可另查历史。

- [ ] 聊天查询能找到记录。
- [ ] 大窗口能找到这份作业。
- [ ] 问题题号里能看到3、5、8。

没有关联知识点时，“尚无确认关联”属于正常状态。

## 测试4：关掉重开，记录还在

操作：关闭两个窗口，等几秒；再次双击同一位置的程序，选学生和数学，刷新作业记录。

- [ ] 同一学生、同一作业仍能找到。
- [ ] 错题号3、5、8仍在。

完整聊天气泡可能清空，不拿它判断作业是否丢失。以查到已保存记录为准。

## 测试5：自己选位置备份

操作：大窗口展开“本地资料与备份”，点“选择文件夹并备份”，选自己知道的位置。

- [ ] 能自己选文件夹。
- [ ] 软件显示“已备份并校验”。
- [ ] 所选文件夹里能找到 backup- 开头的zip文件。

第一次不操作恢复或切换资料目录，不删除练习档案。

## 进阶测试：愿意继续时再做

### 测试6：重复材料不重复建档

操作：再次选择测试2用过的原图，发相同归档指令。

- [ ] 能看到重复材料相关提示。
- [ ] 作业记录没有无提示地多出一份。

### 测试7：补知识点与查看原件

操作：选一份实际看得懂的测试作业和题号，填写知识点、证据原件、附件内页码、原图位置或依据；核对后点“老师确认知识点”。点击“下载原件核对”，在下载位置用电脑看图软件打开。

- [ ] 能保存教师确认的知识点关联。
- [ ] 原件可以下载，并能在电脑上打开。
- [ ] “这个学生的复习线索”有对应依据。

没准备真实题目依据时，这项写“未测”，不要为了勾通过编造学生问题。

### 测试8：真正AI的文字与图片能力

这项需要正确的接口、模型、密钥，可能产生服务费用。只用没有真实身份信息的材料。

操作：按操作说明第六节配置，先测试文字，再选一张图片提出具体问题。

- [ ] 明确看到“文字连接成功”。
- [ ] AI能回答图片中具体内容，不只是问好。
- [ ] 对我自己也看不清的位置，AI没有装作确定。

这项失败不等于本地归档失败；“后端已连接”也不等于这项通过。
