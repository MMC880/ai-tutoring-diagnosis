# 晋学智辅2.0 · 教师试用说明

这是流程试用版，不代表自动批改准确率或教学效果已经验证。

1. 将ZIP**全部解压**到可写的英文目录，例如 `E:\JinxueTrial`。不要在压缩包内运行，也不要单独拿走EXE。双击 `JinxueZhifu.exe`。
2. 主窗口选择学科；AI服务中点“打开 AI Agent”。不配置密钥也能本地收作业、查档；分析题目需要您选择的真实模型。
3. 将**同一名学生、同一份作业**的照片/PDF拖到Agent材料区，输入：“这是九年级一班学生A今天的数学作业，帮我归档。错题是第3、5、8题。”新学生确认一次；已有学生且上下文明确则直接保存。看见“已保存”回执才算完成。
4. 缺日期可先存、以后补。坏图可保存原件，不能冒充识别成功；重复原件会提示。原件每份15MB以内、每组最多12份；模型分析仅支持最多3张图片的去元数据副本，PDF目前只本地保存。
5. 主窗口选学生，进入“知识点与复习”：选作业、题号，查看原件、填写知识点及依据。AI候选不进正式统计；老师确认后进入个人/班级分析。一次错误不等于长期薄弱。
6. 补练内置**仅二次函数顶点式自编演示**。其他知识点可录入老师/Agent准备的三档完整内容（当前为JSON，操作较繁琐，后续需简化）。老师审核后下载一档无解答题面，复测由老师登记。一次答对不等于掌握，原错题始终保留。
7. “老师更正／补日期与缺页”填写更正后的**完整**错题清单及理由，追加修订，不覆盖原件。清空错题清单表示撤回这些错题判断，不表示整卷全对。
8. “本地资料与备份”显示当前资料位置。点“选择文件夹并备份”，生成英文 `backup-*.zip`。恢复只能选新空目录；恢复后不会自动切换。选择“下次启动资料目录”并完全退出重开才切换，旧资料原地保留。

两个保存入口使用同一套学习记录。已有2.0旧手工作业会显示“旧手工作业待续接”，点击续接后原件和旧摘要不改；旧题号仍待核对，请通过“老师更正”确认完整错题清单。班级统计可从实际归档班级中选择，不改变历史归属。知识点更正或错题撤销后，旧补练与复测历史保留，但不能继续下载旧题面或新增该套复测。

默认资料位于EXE旁 `JinxueData/archive`，窗口缓存也在此便携目录；请放E盘等空间充足的位置。不要删除 `JinxueData`。解压新版不会自动迁移旧版，先备份再选择已有2.0资料目录。1.0数据不会自动导入。

真实模型：在主窗口填写接口、模型、密钥，点“配置并测试文字连接”。密钥仅存后端进程内存，完全退出即清除；文字成功不代表图片和工具已成功。发送分析会外发本次文字、所选图片及主动导入的摘要，请先遮去姓名等身份信息；本地原件仍保留。模型推测只能作为待确认建议。

退出：关闭Agent和主窗口或菜单“退出”。只有自己启动的后端会被关闭。若提示端口8019/5179占用，先关闭另一份晋学智辅/开发窗口；不要乱杀其他程序。

已知边界：未验证另一台干净电脑、真人拖拽/系统目录对话框逐项操作、最新真实模型、教学省时；没有自动整卷题目定位、全学科教学库、完整对话持久化或模型自动生成入库的完整闭环。四科入口分开，专用数学内容仅上述演示。CopilotKit仅研发实验，不随试用入口交付。Windows可能显示未签名程序提示，本包尚无商业代码签名。
