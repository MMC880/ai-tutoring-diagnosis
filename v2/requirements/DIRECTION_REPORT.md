# 晋学智辅开发方向对照报告

初稿日期：2026-11-09；2026-11-10追加实施状态。性质：对照过往文档后的纠偏说明，不是冻结PRD；后续开工授权与实际实施分别记在第7、8节。

## 1. 最早方向没有变

最早要做的不是“通用 Agent 工作台”，而是给教培老师用的**学生学习系统**：

1. 学生先完成老师的作业或试卷。
2. 材料进本地档案，按学生长期积累。
3. Agent 辅助找出哪道题有问题、背后缺什么。
4. 老师确认后，再围绕欠缺做讲解和三种难度的举一反三。
5. 下次把该生过往经历再交给 Agent，继续管作业和错题。

约束也一直没变：服务教培老师；山西初中、先数学；数学、英语、物理、化学分开；无心理档案；一次对错不等于掌握或长期薄弱；身份和完整档案留本地；OCR 辅助但不挡手动录入。

对应文档：[PROJECT_VISION.md](../../PROJECT_VISION.md)、[PRD.md](../../PRD.md)、[docs/design/LEARNING_ARCHIVE_MVP_REFOCUS.md](../../docs/design/LEARNING_ARCHIVE_MVP_REFOCUS.md)。

## 2. 已经做成什么，失败在哪

|阶段|实际结果|对产品意味着什么|
|---|---|---|
|1.0 本地应用|学生档案、登记作业、班级学情、确认归档、部分练习复测|业务骨架在，但老师用不明白|

1.0 代码和数据仍在 `app/`，不得推倒。2.0 只放 `v2/`。

## 3. 最近访谈偏到了哪里

压缩上下文后，讨论容易把手段当成产品：

- 问太多建档、日期、红笔识别、知识点标签，像在重做 1.0 的登记表单。
- 把“接 Agent、封装 Skills、四科按钮”说成全部目标，弱化了学习档案。
- 路线图里的 Electron、assistant-ui、CopilotKit 是接入方式，不是交付物。
- 用户要补发的最早计划书还没到；现有附件只是 Agent 工作台路线图，不能当最早计划执行。

没有偏掉的部分：软件是本地壳；Agent 分析题目；壳保存流程实例和结果；下次导入该生经历；四科分开；三级练习是后续能力。

## 4. 正确理解这层壳

壳 = 本地学习档案管理器。它管四科入口、Skill、操作界面、流程实例、学生原件和结果文件。

Agent = 真正看题、归纳错题和欠缺的执行者。通过中转站接口接入。

下次导入的不是整库，而是该生该科可再喂给 Agent 的摘要和必要原件。

## 5. 建议怎么开发，避免再偏

继续用现有仓库和 `v2/`，不新建项目，不重写 1.0 业务库。

**第一刀（最小可演示）**

1. 四个学科按钮：数学、英语、物理、化学；材料按学生+学科分开放。
2. 接上中转站 Agent：配置、连通测试、按内置 Skill 执行任务。
3. 一次任务落地成本地结果：原件保存，生成该生该科 Markdown 摘要（作业、已确认问题、待补项）。
4. 下次打开同一学生同一学科，默认只把最新摘要交回 Agent；原卷另选，不默认塞全部历史照片和其他学科。

数学先跑通这一条。英语、物理、化学先有入口和空档案，不假装已经能分析。

**明确后做**

- 班级共性问题
- 三种难度举一反三
- 完整知识目录和自动出题
- 家长端、收费、多机构

**不再做**

- 重做 1.0 那种多入口复杂表单
- 把 CopilotKit 实验当生产 Agent
- 等最早计划书才开始设计第一刀；计划书只用来核对公开项目，不改产品主线

## 6. 何时算回到正轨

老师点“数学”，选或新建一个学生，拖入一份作业，Agent 分析后本地能打开该生数学摘要；关闭再打开，仍能把这份摘要导入 Agent 继续问“上次错在哪”。

做不到这一步，就还在搭环境和聊天，不能称为进入产品开发。

本报告只整理方向。用户确认“按第一刀开发”后再改业务代码。

## 7. 第一刀已落地（2026-11-10）

用户确认按第一刀开发后，已在`v2/`增量实现：

- 四个学科按钮：数学、英语、物理、化学。
- 用到谁再建谁；重名确认后追加数字。
- 保存该生该科原件，并生成可再导入的 Markdown 摘要。
- 下次可由老师主动点击导入该生该科摘要，不自动携带全部原件和其他学科；当前未实现自动导入历史。

本地档案目录：`v2/.local-data/v2-archive/`。本段为第一刀初始状态；当时Agent仍是本地模拟。1.0 `app/` 未改。

## 8. 指定模型已接入（2026-11-10）

用户提供测试凭据后，沿用现有assistant-ui、httpx、Pillow与中文Skill，接入指定的`deepseek-v4.1-flash-1017`。真实实测完成：文字、多轮、合成图片、受限工具保存待确认笔记、回执、Electron窗口、重启回读。存在间歇HTTP429，不能称稳定可用。

补充“导入这份笔记继续讨论”后，本地模拟服务完成原件保存、笔记再导入和工具读取；该新增步骤尚未通过真实模型复验。正式学生事实仍需老师确认；未重写旧业务库，未打包新版EXE。详见[真实接入报告](REAL_PROVIDER_TEST_REPORT.md)。
