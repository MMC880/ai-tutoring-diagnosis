日期：2026-11-10。工程：`E:\GPT\jinxue-student-first`，分支：`tooling/v2-environment`。本轮沿用现有 `v2/` 第一刀，未修改 1.0 的 `app/`、`packaging/`，未新增或升级依赖。

## 结论

指定模型曾通过一轮真实文字、多轮、合成图片、工具保存、本地回读和 Electron 窗口测试。后续重复测试遇到 HTTP 429，**接口稳定性未通过**。不能把一次成功或本地模拟回归当成稳定可用，更不能据此声称真实学生试卷识别准确率已验证。

本轮采用内置的小型 Agent 执行循环：assistant-ui 展示对话，Python 读取内置中文 Skill，将本次材料交给模型；模型请求受限工具后，由本地代码实际读写并返回回执。不是安装了另一个完整 Agent 平台，也没有把 CopilotKit 实验直接发布为生产功能。

## 已实现的最小流程

1. UI 填写接口、模型、密钥，点击“配置并测试文字连接”。设置接口不返回密钥；配置接受后清空输入框，后端进程退出后需重新输入。
2. assistant-ui 将当前文字、最多 3 张当前图片、最近 10 条文字历史及老师主动导入的摘要交给后端。切换学生或学科会清空当前上下文和保存许可。
3. 数学加载内置“数学错题复盘”Skill。英语、物理、化学目前明确显示通用分析，尚未配置和验收各自的教学 Skill。
4. 模型可调用 `read_selected_summary` 读取本次主动导入的摘要；没有整个档案目录的自由读取权限。
5. 老师选择学生、学科并勾选保存许可后，模型可调用 `save_learning_note`。本地工具限定写入该生该科 `agent-notes/`，实际写盘、刷新、回读后返回路径、字节数和 SHA-256。每次请求最多保存一份笔记。
6. 笔记为 `AI_PENDING_REVIEW`，不是教师已确认的正式学情。UI 可回读笔记，并通过“导入这份笔记继续讨论”准备下次上下文。
7. 原件与摘要可单独保存到本地；不会因为本地保存就自动把原件发给模型。保存原件后清空当前对话附件，需重新选择图片或主动导入摘要。

图片按实际编码解码，支持 PNG/JPEG/WebP/MPO 主帧，重建 PNG 并去掉附带元信息；对话图片源文件每张不超过 2MB、3000 万像素。MPO 的其他帧未用于分析。PDF 目前只可本地保存，未解析或发送给模型。

## 未完成与限制

- 尚未验证真实手写、红笔与学生笔迹区分、整卷识别或教师批改准确率。
- 只替换当前选中学生的称呼，图片重建仅去元信息；这不等于正文和图像已充分去标识。没有验收真实未成年人资料外发隔离。
- 连接失败明确报错；上游超时、取消或后续模型回复失败时，用量或本地写入可能已发生。不能将前端取消视为上游取消，也不能盲目重发。
- 当前密钥仅进程内存，无生产级持久密钥管理、本地 API 身份认证或 DNS 层内网隔离。
- 档案采用本地文件和 JSON 索引，没有事务、崩溃恢复和并发写入验收；请求内重复工具调用复用回执，不构成跨请求幂等。
- 老师说明中的题号仍用初步数字提取，日期、分数等数字可能误入候选，必须核对；尚未实现完整自然语言业务登记。
- 对话本身未持久化；刷新会清空。仅主动保存的原件、摘要和待确认笔记保留，不等于完整流程实例已实现。
- 保存笔记后需手动导入才能成为下一次上下文，没有自动检索整库或自动累积“长期薄弱”结论。
- 当前默认本地工作目录尚无老师自选资料根目录的入口；未封装新版 EXE，未在干净 Windows 机器验收。
- CopilotKit 仍为独立开发实验；生产接入和授权问题未解决。LangGraph/Taro 未引入。
- 沿用构建中的 CopilotKit 大包警告与 Starlette/httpx 测试弃用提醒；不因此擅自升级依赖。
