## 本轮结论

已接通“选择当前学生、学科和作业 → 授权 → Agent 工具读取结构化历史 → 按需读取一张归档图片 → 保存待确认笔记和 MD”。沿用现有数据库、原件存储、知识点关联、模型工具循环和笔记写入，不重构、不迁移数据、不改训练与复测。

本轮使用合成学生的两次作业，实际运行 Electron、生产前端、FastAPI、SQLite 和本地文件读写。**仅外部模型 HTTP 回复使用确定性替身，工具选择也由替身预设。** 这证明连接和保存实际执行，不能证明真实模型会自主正确选择工具、识别图片或分析错因。旧 `2.0.0-preview.3` EXE 未更新，本轮未封装新 EXE。

## 复用与职责

| 组成 | 本轮行为 | 复用内容 |
| --- | --- | --- |
| SQLite 与原件索引 | 限定学生、学科、作业，读取当前有效题号和关联状态 | `LearningService.workspace/assignment/original`，原件 SHA-256 校验 |
| Agent | 请求只读工具，根据实际返回内容提出待确认建议 | 既有 `ProviderService` 与最多 4 轮工具循环 |
| MD | 保存分析、待确认状态与实际工具来源 | 既有 `save_learning_note`，独占创建、fsync、回读及哈希回执 |
| 窗口 | 主窗口所选作业带入独立 Agent，增加折叠授权区 | 既有窗口 IPC、学生学科切换和聊天界面 |

新增 `backend/agent_history.py` 是本次请求的受限只读桥接，没有新增业务表。正式错题、知识点确认、统计、训练和复测不由这些工具改写。

### 三个读取工具

- `search_student_history(query, offset)`：仅查当前授权学生当前学科的结构化作业、错题与知识点摘要。每页最多 10 份，可继续翻页；不默认发送图片。这是文字匹配，不是语义检索，无命中不代表从未发生。
- `read_assignment(assignment_id, number)`：按作业和可选题号读取当前有效教师题号、候选题号、知识点状态、修订、原件哈希、页码和证据摘录。未保存题干或作答的题，明确缺少内容，不能据此编造作答。单份最多返回 20 条关联，并返回总数和截断标记。
- `read_assignment_image(assignment_id, sha256)`：先核验学生学科范围与原件哈希，再生成既有去元数据图片分析副本，随下一次模型请求发送。单次请求合计最多 3 张（含新附件），最长边 2000 像素、JPEG 副本不超过 2MB。MPO 仅主帧。PDF、损坏、缺失或校验失败返回 `UNREADABLE`，不假装识别。

工具参数不接受学生、学科覆盖或任意文件路径。原件读取在调用已有原件接口前先验证范围。工具返回区分教师明确提供、AI／手工候选和教师确认知识点；已撤销题号的关联只作为历史，不能伪装成当前错题。

### 授权与待确认保存

历史记录、归档原图、保存待确认笔记分别授权，默认关闭。只授权原图时，范围限所选作业；同时授权历史后，才可按需请求该生该科的历史原图。切换学生、学科或重开窗口不继承授权。

取消历史或原图授权时，旧对话不再随下一条请求重发，主动导入摘要也清空；已经保存的本地笔记保留。已经发出的请求无法追回，正在执行时授权控件禁用。

待确认 MD 状态为 `AI_PENDING_REVIEW`。软件在保存时追加截至该时刻实际工具读取回执，包含工具名、时间、作业／题号／页码／哈希等来源及读取结果。`READ_IMAGE` 表示分析副本已生成供下一次请求发送；传输失败时不能声称模型已看到。回执证明读取动作，不认证 AI 结论或引用内容正确。

2. 未授权直接要求分析，返回本地提示，模型接口零调用。

5. 实际调用保存工具，写出带两次作业引用及真实读取回执的待确认 MD，检查回读与哈希。
6. 撤销读取授权后发出新消息，实际检查下一次模型请求不再包含上次作业对话、摘要或已撤销工具。
7. 比较读取前后的整个学情工作区及原件字节哈希：保持一致；关闭、重开 Agent 后仍能读回笔记。后端测试另验证应用重新创建后仍能读回笔记。

保存的分析表述为：两次题目已有同知识点关联；是否同一错因仍待核实；历史原图未读取；不能认定长期薄弱。该表述由模拟模型生成，不能算真实模型推理结果。

## 本轮限制与停止点

- 真实供应商的工具调用、多模态识别、分析质量、费用和老师实际体验未验证；不宣称批改准确率。
- PDF 未渲染；题干／学生过程不在结构化记录中时，只能请求可靠图片或明确缺少材料。图片副本压缩后细字可能看不清。
- 搜索是分页文字匹配，未续接旧作业、外部任意 MD 和其他历史 AI 笔记不会自动全部索引；笔记仍可通过现有入口主动导入。
- 工具循环最多 4 轮，单轮最多 4 个调用。模型可能未调用保存工具或达到上限；以实际回执判定，不保证每条回复自动保存。MD 记录保存时刻之前的读取，之后的读取不会倒写该文件。
- AI 文本中的引用和判断不做自动事实认证；只替换已知学生称呼／班级，不是完整个人信息去标识。当前本机单进程信任边界未扩展。
- 没有更换 Agent 框架，没有扩展训练、复测或主界面；旧 EXE 未封装更新。停止在“读取 → 引用 → 待确认保存”的验收点。
