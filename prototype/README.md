# 老师工作台交互原型 v0.1

直接双击 index.html，用电脑浏览器打开。无需安装、登录或联网。移动时请复制整个 prototype 文件夹，保留 assets、styles.css 和 app.js。

建议体验顺序：

1. 作业审核：对照合成照片，切换四题，试一下“校正识别”和结果选择。
2. 点击“确认此学生整卷”，核对确认范围，勾选后完成本页演示确认。
3. 打开学习档案、班级共性，查看个人证据和已确认结果；十人模拟卷是另外一份六题样例。
4. 在补练与复测选择一档，生成教师审稿，查看答案，批准当前单题。
5. 录入虚构复测，返回档案查看新证据；原错题保留，不自动判掌握。
6. 试导出格式选择和取消。这里只演示操作，不生成 Word/PDF。

所有数据均为虚构，所有确认／归档／批准仅存在页面内存。刷新或重置会恢复初始状态，不调用AI、不读取真实作业、不写磁盘档案，不修改WorkBuddy的62条事件。原型不构成安全隔离、可靠存储或正式产品实现。

原图为本项目已生成的合成照片，标有“非真实学生作业”。完整初中数学是产品方向；四题只用于操作示意，不代表覆盖率。

界面方案属于可修改提案。请重点评审：整卷对照是否清楚、审核按钮是否顺手、个人记录与共性是否分明、补练和复测是否容易理解。
